# 一般混凝土框架-剪力墙结构布置规则

单位 mm。

## 1 体系与整体控制

**M — Mandatory（应）**
- **M-1.1** 双向抗侧力体系：抗震设计时结构两主轴方向均应布置剪力墙，不应采用仅单向有墙的布置
- **M-1.2** 最大适用高度
  - **M-1.2.1** A 级高度：非抗震 150000；6 度 130000；7 度 120000；8 度(0.2g) 100000；8 度(0.3g) 80000；9 度 50000
  - **M-1.2.2** B 级高度：非抗震 170000；6 度 160000；7 度 140000；8 度(0.2g) 120000；8 度(0.3g) 100000
- **M-1.3** 最大高宽比：非抗震 ≤ 7；6 度、7 度 ≤ 6；8 度 ≤ 5；9 度 ≤ 4
- **M-1.4** 平面尺寸：6、7 度 L/B ≤ 6.0、l/B_max ≤ 0.35、l/b ≤ 2.0；8、9 度 L/B ≤ 5.0、l/B_max ≤ 0.30、l/b ≤ 1.5
- **M-1.5** 扭转控制
  - **M-1.5.1** 扭转位移比：在考虑偶然偏心影响的规定水平地震力作用下，楼层竖向构件最大水平位移和层间位移，A 级高度不宜大于该楼层平均值的 1.2 倍、不应大于 1.5 倍；B 级高度不宜大于 1.2 倍、不应大于 1.4 倍
  - **M-1.5.2** 扭转周期比：扭转为主第一自振周期 T_t 与平动为主第一自振周期 T_l 之比，A 级高度不应大于 0.9，B 级高度不应大于 0.85；当楼层最大层间位移角不大于限值的 0.4 倍时，上述比值可适当放宽，但不应大于 1.6
- **M-1.6** 楼板削弱：有效楼板宽度不宜小于该层楼面宽度的 50%；楼板开洞总面积不宜超过楼面面积的 30%；扣除凹入或开洞后楼板在任一方向的最小净宽度不宜小于 5000；开洞后每一边的楼板净宽度不应小于 2000
- **M-1.7** 竖向规则性
  - **M-1.7.1** 侧向刚度比：本层与相邻上层侧向刚度之比不宜小于 0.9；本层层高大于相邻上层层高的 1.5 倍时不宜小于 1.1；底部嵌固层不宜小于 1.5
  - **M-1.7.2** 层间受剪承载力比：A 级高度不宜小于相邻上层受剪承载力的 80%，不应小于 65%；B 级高度不宜小于相邻上层受剪承载力的 75%
  - **M-1.7.3** 楼层收进与外挑：上部楼层收进部位到室外地面的高度 H1 与房屋高度 H 之比大于 0.2 时，收进后水平尺寸 B1 不宜小于下部楼层水平尺寸 B 的 0.75 倍；上部楼层外挑时 B1 不宜大于 B 的 1.1 倍，水平外挑尺寸 a 不宜大于 4000
  - **M-1.7.4** 楼层质量：上层楼层质量不宜大于相邻下部楼层质量的 1.5 倍
  - **M-1.7.5** 剪力增大系数：侧向刚度变化、承载力变化、竖向抗侧力构件连续性不符合 M-1.7.1~1.7.4 的楼层，其对应于地震作用标准值的剪力应乘以 1.25
- **M-1.8** 弹性层间位移角限值（多遇地震）：≤ 1/800；房屋高度 150000~250000 之间时按 1/800 与 1/500 线性插值取用；高度不小于 250000 时不宜大于 1/500
- **M-1.9** 罕遇地震作用下弹塑性层间位移角限值：≤ 1/100；转换层 ≤ 1/120
- **M-1.10** 框架与剪力墙受力分工分档（按底层框架部分地震倾覆力矩 / 结构总地震倾覆力矩）：≤ 10% 时按剪力墙结构设计，其中框架部分按框架-剪力墙结构的框架设计；> 10% 且 ≤ 50% 时按框架-剪力墙结构设计；> 50% 且 ≤ 80% 时按框架-剪力墙结构设计，最大适用高度可比框架结构适当增加，框架部分的抗震等级和轴压比限值宜按框架结构规定采用；> 80% 时按框架-剪力墙结构设计，最大适用高度宜按框架结构采用，框架部分的抗震等级和轴压比限值应按框架结构规定采用
- **M-1.11** 框架总剪力下限：对应于地震作用标准值的各层框架总剪力应满足 Vf ≥ 0.2V0；不满足的楼层，其框架总剪力应按 0.2V0 和 1.5Vf.max 二者的较小值采用
- **M-1.12** 主体连接：主体结构构件之间除个别节点外不应采用铰接；梁与柱或柱与剪力墙的中线宜重合

**R — Recommended（宜）**
- **R-1.1** 剪力墙布置位置宜均匀布置在建筑物的周边附近、楼梯间、电梯间、平面形状变化及恒载较大的部位；平面形状凹凸较大时宜在凸出部分端部附近布置；纵、横剪力墙宜组成 L 形、T 形和 [] 形；楼、电梯间等竖井宜尽量与靠近的抗侧力结构结合布置；宜使结构各主轴方向的侧向刚度接近（两方向刚度比宜控制在 1.0~1.5，工程控制值）
- **R-1.2** 平面和竖向均不规则的结构，最大适用高度宜适当降低（不宜大于 M-1.2.1、M-1.2.2 表列值的 0.9 倍，工程控制值）

**F — Forbidden（禁）**
- **F-1.1** 角部重叠或细腰形平面
- **F-1.2** 抗震设计时仅单向布置剪力墙
- **F-1.3** 扭转位移比超过 A 级 1.5 倍或 B 级 1.4 倍，或扭转周期比超过 A 级 0.9 / B 级 0.85
- **F-1.4** 楼层侧向刚度比低于 M-1.7.1（本层与相邻上层 < 0.9；层高突变时 < 1.1；底部嵌固层 < 1.5）
- **F-1.5** 层间受剪承载力低于相邻上层的 80%（A 级）或 75%（B 级）
- **F-1.6** 楼层质量大于相邻下部楼层质量的 1.5 倍
- **F-1.7** 上部楼层收进后水平尺寸 < 0.75B，或水平外挑尺寸 > 4000
- **F-1.8** 弹性层间位移角超过 M-1.8

## 2 剪力墙布置

**M — Mandatory（应）**
- **M-2.1** 剪力墙截面厚度：一、二级底部加强部位 ≥ 200、其他部位 ≥ 160；一字形独立剪力墙（一、二级）底部加强部位 ≥ 220、其他部位 ≥ 180；三、四级 ≥ 160，一字形独立剪力墙（三、四级）底部加强部位 ≥ 180；非抗震设计 ≥ 160；剪力墙井筒中分隔电梯井、管道井的墙肢不宜 < 160；并应同时满足比例限值——抗震墙厚度不宜小于层高或无支长度的 1/20，底部加强部位不宜小于层高或无支长度的 1/16
- **M-2.2** 短肢剪力墙（截面厚度不大于 300、且各肢截面高度与厚度之比的最大值大于 4 但不大于 8 的剪力墙）截面厚度（抗震设计）：底部加强部位 ≥ 200，其他部位 ≥ 180；轴压比限值一、二、三级分别 ≤ 0.45、0.50、0.55；一字形截面短肢剪力墙的轴压比限值相应减少 0.1
- **M-2.3** 底部加强部位高度：应从地下室顶板算起，取底部两层和墙体总高度的 1/10 二者的较大值；带转换层结构时宜取至转换层以上两层且不宜小于房屋高度的 1/10；当结构计算嵌固端位于地下一层底板或以下时，底部加强部位宜延伸到计算嵌固端
- **M-2.4** 墙段划分：各墙段的高度与墙段长度之比不宜小于 3；墙段长度不宜大于 8000
- **M-2.5** 单片剪力墙底部承担的水平剪力不应超过结构底部总水平剪力的 30%
- **M-2.6** 边缘构件：剪力墙两端和洞口两侧应设置边缘构件；约束边缘构件沿墙肢的长度（暗柱）≥ 墙厚与 400 的较大值；有翼墙或端柱时 ≥ 翼墙厚度或端柱沿墙肢方向的截面高度加 300；一、二、三级剪力墙底层墙肢底截面轴压比超过规定值时应设约束边缘构件，其余部位设构造边缘构件，B 级高度宜在两者之间设 1~2 层过渡层
- **M-2.7** 楼面梁不宜支承在剪力墙或核心筒的连梁上
- **M-2.8** 楼面梁与剪力墙平面外刚接时的墙、柱尺寸：沿梁轴线设置与梁相连的剪力墙时，墙的厚度不宜小于梁的截面宽度；设置扶壁柱时，其截面宽度不应小于梁宽，截面高度可计入墙厚；墙内设置暗柱时，暗柱截面高度可取墙的厚度，暗柱截面宽度可取梁宽加 2 倍墙厚
- **M-2.9** 短肢剪力墙布置限制：高层建筑结构不应全部采用短肢剪力墙；B 级高度高层建筑以及 9 度 A 级高度高层建筑不宜布置短肢剪力墙，不应采用具有较多短肢剪力墙的剪力墙结构；采用具有较多短肢剪力墙的剪力墙结构时，短肢剪力墙承担的底部倾覆力矩不宜大于结构底部总地震倾覆力矩的 50%，房屋适用高度在 7 度、8 度(0.2g)、8 度(0.3g) 时分别不应大于 100000、80000、60000
- **M-2.10** 带边框剪力墙：抗震设计时一、二级剪力墙的底部加强部位厚度 ≥ 200，其他情况下 ≥ 160；与剪力墙重合的框架梁可做成宽度与墙厚相同的暗梁，暗梁截面高度可取墙厚的 2 倍或与该榀框架梁截面等高；边框柱截面宜与该榀框架其他柱的截面相同
- **M-2.11** 剪力墙最大间距（长矩形平面中横向剪力墙沿长方向的间距，B 为剪力墙之间的楼面宽度）：现浇楼盖 7 度 ≤ min(4.0B, 50000)、8 度 ≤ min(3.0B, 40000)；装配整体楼盖 7 度 ≤ min(3.0B, 40000)、8 度 ≤ min(2.5B, 30000)；6 度不限；当剪力墙之间的楼盖有较大开洞时，剪力墙间距应适当减小；纵向剪力墙不宜集中布置在房屋的两尽端；当房屋端部未布置剪力墙时，第一片剪力墙与房屋端部的距离不宜大于表中剪力墙间距的 1/2
- **M-2.12** 小洞口与穿管：开边长小于 800 的小洞口且在结构整体计算中不考虑其影响时，应在洞口上、下和左、右作补强处理；穿过连梁的管道宜预埋套管，洞口上、下截面有效高度不宜小于梁高的 1/3，且不宜小于 200

**R — Recommended（宜）**
- **R-2.1** 较长剪力墙宜设置跨高比大于 6 的连梁，将其分成长度较均匀的若干墙段
- **R-2.2** 不宜采用一字形短肢剪力墙；不宜在一字形短肢剪力墙上布置平面外与之相交的单侧楼面梁
- **R-2.3** 剪力墙宜自下到上连续布置，避免刚度突变；相邻楼层墙肢宽度变化不宜大于 25%（工程控制值）

**F — Forbidden（禁）**
- **F-2.1** 一、二、三级剪力墙底部加强部位采用上下洞口不对齐的错洞墙
- **F-2.2** 剪力墙全高采用洞口局部重叠的叠合错洞墙
- **F-2.3** 高层建筑结构全部采用短肢剪力墙
- **F-2.4** 楼面梁支承在剪力墙或核心筒的连梁上

## 3 框架柱、框架梁与连梁

**M — Mandatory（应）**
- **M-3.1** 框架柱网：柱距 ≤ 8400；同一方向相邻两跨柱距之比 ≤ 1.2；开间不宜 < 2100 或 > 8400
- **M-3.2** 框架柱截面：抗震 b ≥ 350、h ≥ 400；非抗震 ≥ 300×300；b/h ≥ 0.7；柱净高与截面高度之比 H_n/h_c ≥ 3；长细比 λ = H₀/h_c ≤ 25（抗震）/30（非抗震）
- **M-3.3** 框架梁：主梁 h = l₀/10~12（控制 l₀/h ≤ 12，抗震取 ≤ 10）；次梁 l₀/12~15；悬臂根部 l₀/8~10 且 ≥ 80；高宽比 h/b ≤ 4；主梁截面高 ≥ 400（跨度 ≥ 6000）、次梁 ≥ 200、一般 ≥ 250
- **M-3.4** 连梁跨高比分界：跨高比小于 5 的连梁应按剪力墙连梁的规定设计，跨高比不小于 5 的连梁宜按框架梁设计
- **M-3.5** 连梁截面削弱限制：管道穿孔处洞口上、下截面有效高度不宜小于梁高的 1/3，且不宜小于 200；边长小于 800 的小洞口按 M-2.12 处理
- **M-3.6** 转换层控制：转换层上下的结构质量中心宜接近重合；转换层位于第 1、2 层时，转换层下部与上部结构等效侧向刚度比抗震设计 ≥ 0.8、非抗震 ≥ 0.5，等效剪切刚度比抗震 ≥ 0.5、非抗震 ≥ 0.4；转换层位于第 2 层以上时，按楼层侧向刚度比计算的该比值 ≥ 0.6；转换层楼盖不应有大洞口，在平面内宜接近刚性；转换层楼盖与抗震墙应有可靠的连接；厚板转换层不宜用于 7 度及 7 度以上的高层建筑；8 度时应考虑竖向地震作用；9 度时不应采用转换层结构；转换层还应满足 M-1.7 的竖向规则性要求并采用现浇楼盖结构（M-4.1）
- **M-3.7** 转换构件截面：转换梁截面高度不宜小于计算跨度的 1/8；转换柱截面宽度非抗震不宜小于 400、抗震不应小于 450，截面高度非抗震不宜小于转换梁跨度的 1/15、抗震不宜小于转换梁跨度的 1/12

**R — Recommended（宜）**
- **R-3.1** 常用截面起步值（工程控制值）：柱 400×400~600×700；主梁 4200→400×300、5400→500×300、6000→600×300、7200→700×350、8400→800×400；次梁 250×150~400×200
- **R-3.2** 柱距取 100 的整数倍，优选 600 模数（4200/5400/6000/7200/8400）；住宅开间 2400~3600，办公商业开间 3600~8400（工程控制值）
- **R-3.3** 当墙肢的截面高度与厚度之比不大于 4 时，宜按框架柱进行截面设计
- **R-3.4** 连梁截面尺寸（工程控制值）：截面高度 ≥ 400，宜取净跨 l₀ 的 1/8~1/10；截面宽度不宜小于墙厚

**F — Forbidden（禁）**
- **F-3.1** 框架梁 h/b > 4
- **F-3.2** 主梁 l₀/h > 12
- **F-3.3** 柱净高与截面高度之比小于 3 的短柱
- **F-3.4** 上下层框架柱截面突变 > 25%
- **F-3.5** 9 度时采用转换层结构

## 4 楼盖与板

**M — Mandatory（应）**
- **M-4.1** 现浇楼盖要求：房屋高度超过 50000 时应采用现浇楼盖结构；房屋的顶层、结构转换层、大底盘多塔楼结构的底盘顶层、平面复杂或开洞过大的楼层、作为上部结构嵌固部位的地下室楼层应采用现浇楼盖结构
- **M-4.2** 楼板厚度
  - **M-4.2.1** 一般楼层：现浇楼板 ≥ 80，板内预埋暗管时不宜 < 100
  - **M-4.2.2** 顶层楼板：≥ 120
  - **M-4.2.3** 普通地下室顶板：≥ 160
  - **M-4.2.4** 作为上部结构嵌固部位的地下室楼层顶楼盖：应采用梁板结构，楼板厚度 ≥ 180
- **M-4.3** 板的跨厚比：单向 ≥ l₀/30；双向 ≥ l₀/40（常用 l₀/35~45）；悬挑根部 ≥ l₀/10~12；现浇预应力混凝土楼板厚度可按跨度的 1/45~1/50 采用，且不宜小于 150

**R — Recommended（宜）**
- **R-4.1** 常用板厚（工程控制值）：住宅 120（厨卫 150）、办公 120~150、板跨 ≥ 8400 取 180~250
- **R-4.2** 无梁楼盖板厚 l₀/25~30，设柱帽/托板 300~500

**F — Forbidden（禁）**
- **F-4.1** 楼板厚度低于 M-4.2.1~4.2.4、M-4.3 的限值
- **F-4.2** 房屋高度超过 50000 时采用非现浇楼盖
- **F-4.3** 同层板厚突变 > 1/3 板厚

## 5 缝与基础

**M — Mandatory（应）**
- **M-5.1** 伸缩缝最大间距：现浇框架-剪力墙结构宜取框架结构（室内 55000、露天 35000）与剪力墙结构（室内 45000、露天 30000）之间的数值；屋面无保温或隔热措施时按露天栏数值取用
- **M-5.2** 伸缩缝、沉降缝的宽度均应符合 M-5.3 关于防震缝宽度的要求
- **M-5.3** 防震缝宽度：框架-剪力墙结构不应小于框架结构数值（框架结构房屋高度不超过 15000 时不应小于 100；超过 15000 时，6 度、7 度、8 度、9 度分别每增加高度 5000、4000、3000、2000，宜加宽 20）的 70%，且不宜小于 100；两侧结构体系不同时按不利者确定，两侧高度不同时可按较低者确定
- **M-5.4** 防震缝宜沿房屋全高设置；地下室、基础可不设缝，但应在与上部缝对应处加强
- **M-5.5** 后浇带：间距 ≤ 40000、带宽 800~1000；后浇带混凝土龄期 ≥ 60 d（JGJ 3-2010 3.4.13 规定宜在 45 d 后浇灌，本规则从严）
- **M-5.6** 沉降缝：最大间距 ≤ 30000；缝宽 ≥ 30~50；缝两侧留 ≥ 100 净距
- **M-5.7** 基础埋深 ≥ 1000；柱边至承台边 ≥ 50；天然地基或复合地基的基础埋深可取房屋高度的 1/15，桩基础（不计桩长）可取房屋高度的 1/18
- **M-5.8** 承台厚度 ≥ 400（桩基 ≥ 800、端承桩 ≥ 1000）；垫层厚 100
- **M-5.9** 基础梁 h ≥ 400、b ≥ 300；基础长宽比 ≤ 1.5
- **M-5.10** 基础底面零应力区：高宽比大于 4 的高层建筑，基础底面不宜出现零应力区；高宽比不大于 4 时，零应力区面积不应超过基础底面面积的 15%

**R — Recommended（宜）**
- **R-5.1** 缝两侧宜各自成柱、不共用柱，刚度与荷载尽量接近；缝边不得有悬挑构件
- **R-5.2** 超过伸缩缝最大间距时，宜优先采用后浇带（M-5.5）替代整条伸缩缝
- **R-5.3** 基础形式：高层建筑宜采用筏形基础或带桩基的筏形基础，必要时可采用箱形基础

**F — Forbidden（禁）**
- **F-5.1** 结构单元之间或主楼与裙房之间采用牛腿托梁的做法设置防震缝
- **F-5.2** 伸缩缝间距超过 M-5.1 限值
- **F-5.3** 防震缝两侧共用柱
