# 一般混凝土框架结构 修订记录

配套文件：《一般混凝土框架结构布置规则.md》（条文）、《一般混凝土框架结构布置规则-条文说明.md》（条文说明）。

| 版本 | 变更 |
|---|---|
| 2026-11-26 | 条文 M-1.4 原写作"H_n/h_c ≤ 3（否则成短柱）"，不等式方向有误，已改为 **H_n/h_c ≥ 3**（净高与截面高度之比过小才构成短柱）。相应地 F-1.2 的短柱判据保持不变。 |
| 2026-11-26 | 条文 M-1.6 与条文说明 M-1.6 的**伸缩缝露天最大间距由 45000 修正为 35000**。依据 GB 50010-2010 表 8.1.1 与 JGJ 3-2010 表 3.4.12，框架结构现浇的露天最大间距为 35000（室内 55000）；原值 45000 实为剪力墙结构的室内限值，属张冠李戴。 |
| 2026-11-26 | 伸缩缝、沉降缝、防震缝等条款的规范号表述按 GB/T 50011-2010(2024年版)《建筑抗震设计标准》更新（GB 50011-2010 已于 2024-08-01 局部修订并更名），条文号按新版核对。 |
| 2026-11-26 | 修订记录自本文件独立成篇，原《一般混凝土框架结构布置规则-条文说明.md》末尾的"修订记录"章节移入本文件，条文说明正文不再重复。 |
| 2026-11-26 | 体例统一：文件与标题中的「布置原则」改为「布置规则」（`一般混凝土框架结构布置规则.md`、`一般混凝土框架结构布置规则-条文说明.md`）；各规则书内重复的「编号规则」小节按 README 已给出统一说明的要求整体移除，条文仅保留规则正文。 |
