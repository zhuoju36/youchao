# 混凝土框架-核心筒结构布置规则

单位 mm。

**适用范围**：本文件适用于钢筋混凝土框架-核心筒结构（外围框架 + 钢筋混凝土核心筒）的高层房屋布置设计。房屋高度不超过 24m 或不属高层建筑的同类结构可参照执行。**本文件不适用于钢框架、钢结构、型钢-混凝土组合结构、钢管混凝土结构**，该类体系另按相应规范执行。

## 1 体系与整体控制

**M — Mandatory（应）**
- **M-1.1** 适用最大高度（A 级，房屋高度 ≤ 室外地面至主要屋面板板顶，不含局部突出屋顶部分）：非抗震 160000；6 度 150000；7 度 130000；8 度（0.20g）100000；8 度（0.30g）90000；9 度 70000
- **M-1.2** 适用最大高度（B 级）：非抗震 220000；6 度 210000；7 度 180000；8 度（0.20g）140000；8 度（0.30g）120000；平面和竖向均不规则的结构，最大适用高度宜适当降低
- **M-1.3** 高宽比：非抗震 ≤ 8；6、7 度 ≤ 7；8 度 ≤ 6；9 度 ≤ 4
- **M-1.4** 平面尺寸：L/B ≤ 6.0（6、7 度）/5.0（8、9 度）；l/B_max ≤ 0.35/0.30；l/b ≤ 2.0/1.5；不宜采用角部重叠或细腰形平面
- **M-1.5** 扭转：A 级高度楼层竖向构件最大水平位移与层间位移不宜大于该楼层平均值的 1.2 倍、不应大于 1.5 倍；B 级高度不宜大于 1.2 倍、不应大于 1.4 倍；扭转为主第一自振周期 T_t 与平动为主第一自振周期 T_l 之比，A 级 ≤ 0.9、B 级 ≤ 0.85；该层最大层间位移角 ≤ 限值 0.4 倍时上述比值可放宽，但不应大于 1.6
- **M-1.6** 楼层侧向刚度比：本层与相邻上层 ≥ 0.9；本层层高 > 相邻上层层高的 1.5 倍时 ≥ 1.1；结构底部嵌固层 ≥ 1.5
- **M-1.7** 楼层抗侧力结构层间受剪承载力：A 级高度 ≥ 相邻上层受剪承载力的 80% 且 ≥ 65%；B 级高度 ≥ 75%
- **M-1.8** 上部楼层收进部位至室外地面的高度 H_1 与房屋高度 H 之比 > 0.2 时，收进后水平尺寸 B_1 ≥ 0.75B；上部楼层外挑时 B_1 ≤ 1.1B，水平外挑尺寸 a ≤ 4000
- **M-1.9** 楼层质量 ≤ 相邻下部楼层质量的 1.5 倍
- **M-1.10** 侧向刚度、承载力或竖向抗侧力构件连续性不符合 M-1.6~M-1.9 的楼层，其地震作用标准值对应的剪力 × 1.25
- **M-1.11** 层间位移角：多遇地震弹性层间位移角 ≤ 1/800；罕遇地震弹塑性层间位移角 ≤ 1/100；除框架结构的转换层 ≤ 1/120；房屋高度 ≥ 250000 时弹性层间位移角 ≤ 1/500，房屋高度 150000~250000 时按 1/800 与 1/500 线性插入
- **M-1.12** 外围框架承担的地震剪力：按侧向刚度分配的最大楼层地震剪力标准值 ≥ 结构底部总地震剪力标准值的 10%；小于 10% 时各层框架承担的地震剪力标准值应增大到 15%，同时核心筒墙体地震剪力标准值 × 1.1（但不大于结构底部总地震剪力标准值），核心筒抗震构造措施按抗震等级提高一级（已为特一级的可不再提高）；小于 20% 但最大值 ≥ 10% 时，按结构底部总地震剪力标准值的 20% 与框架部分楼层地震剪力标准值最大值的 1.5 倍二者中的较小值调整
- **M-1.13** 楼板削弱：有效楼板宽度 ≥ 该层楼面宽度的 50%；楼板开洞总面积 ≤ 楼面面积的 30%；扣除凹入或开洞后楼板在任一方向的最小净宽度 ≥ 5000；开洞后每一边的楼板净宽度 ≥ 2000

**R — Recommended（宜）**
- **R-1.1** 房屋高度 ≤ 60000 的框架-核心筒结构，可按框架-剪力墙结构设计（按框剪设计时框架部分的抗震构造不得降低）
- **R-1.2** 常用层高 3000~4000；核心筒内楼梯间净宽 ≥ 2200，电梯井净宽 ≥ 2400（工程控制值）
- **R-1.3** 外围框架宜形成周边框架：外围框架柱之间均设框架梁，构成连续闭合的周边抗侧力体系

**F — Forbidden（禁）**
- **F-1.1** 房屋高度超过 M-1.1/M-1.2 规定值仍按常规体系设计（超限须专项论证）
- **F-1.2** 高宽比超过 M-1.3
- **F-1.3** 扭转超限：A 级高度楼层位移比 > 1.5，或 T_t/T_l > 0.9；B 级高度楼层位移比 > 1.4，或 T_t/T_l > 0.85
- **F-1.4** 楼层侧向刚度比 < 0.9（层高突变时 < 1.1，底部嵌固层 < 1.5）
- **F-1.5** 层间受剪承载力低于相邻上层的 80%（A 级）或 75%（B 级）
- **F-1.6** 楼层质量 > 相邻下部楼层质量的 1.5 倍
- **F-1.7** 上部楼层收进后 B_1 < 0.75B，或水平外挑尺寸 a > 4000
- **F-1.8** 外围框架承担的地震剪力最大值 < 10% 而未按 M-1.12 调整至 15%
- **F-1.9** 楼板开洞总面积 > 楼面面积的 30%，或有效楼板宽度 < 楼面宽度的 50%

## 2 核心筒布置

**M — Mandatory（应）**
- **M-2.1** 核心筒宽度 ≥ 筒体总高的 1/12（设置角筒、剪力墙或其他增强整体刚度的构件时可适当减小）
- **M-2.2** 筒壁墙厚：核心筒外墙 ≥ 200；内墙 ≥ 160；其他部位墙厚不宜小于层高或无支长度的 1/20，底部加强部位墙厚不宜小于层高或无支长度的 1/16；尚应满足墙体平面外稳定验算要求，必要时可设置扶壁柱或扶壁墙
- **M-2.3** 核心筒底部加强部位及相邻上一层，侧向刚度无突变时不宜改变墙体厚度
- **M-2.4** 筒角开洞：筒体角部附近不宜开洞；不可避免时，筒角内壁至洞口的距离 ≥ 500 且 ≥ 开洞墙截面厚度的较大值
- **M-2.5** 核心筒外墙不宜在水平方向连续开洞；洞间墙肢的截面高度 ≥ 1200；洞间墙肢截面高度与厚度之比 < 4 时，宜按框架柱进行截面设计
- **M-2.6** 核心筒外墙与外框柱之间的中距：非抗震设计 > 15000、抗震设计 > 12000 时，宜增设内柱
- **M-2.7** 底部加强部位高度：自地下室顶板算起，取底部两层与墙体总高度的 1/10 二者中的较大值；结构计算嵌固端位于地下一层底板或以下时，宜延伸至计算嵌固端；带转换层时宜取至转换层以上两层且不宜小于房屋高度的 1/10
- **M-2.8** 核心筒连梁跨高比 < 5 时按剪力墙连梁规定设计，≥ 5 时宜按框架梁设计；跨高比 ≤ 2 的连梁宜增配对角斜向钢筋，跨高比 ≤ 1 的连梁宜采用交叉暗撑，此时连梁截面宽度 ≥ 400
- **M-2.9** 墙肢的截面高度与厚度之比 ≤ 4 时，宜按框架柱进行截面设计
- **M-2.10** 核心筒墙肢宜均匀、对称布置；核心筒或内筒中剪力墙的截面形状宜简单
- **M-2.11** 核心筒内分隔电梯井或管道井的墙肢截面厚度可适当减小，但不宜小于 160
- **M-2.12** 楼面梁不宜支承在核心筒的连梁上；楼盖主梁不宜搁置在核心筒或内筒的连梁上
- **M-2.13** 楼面梁与核心筒墙平面外刚接时：沿梁轴线设置与梁相连的剪力墙时，墙厚 ≥ 梁的截面宽度；设置扶壁柱时，其截面宽度 ≥ 梁宽，截面高度可计入墙厚；墙内设置暗柱时，暗柱截面高度取墙的厚度、暗柱截面宽度取梁宽加 2 倍墙厚
- **M-2.14** 内筒偏置（单侧布置核心筒）时，最大楼层水平位移和层间位移 ≤ 该楼层平均值的 1.4 倍；扭转为主第一自振周期 T_t 与平动为主第一自振周期 T_l 之比 ≤ 0.85；T_l 的扭转成分 ≤ 30%
- **M-2.15** 核心筒角部墙肢的约束边缘构件：底部加强部位角部墙体的约束边缘构件沿墙肢的长度 ≥ 墙肢截面高度的 1/4；底部加强部位以上角部墙体宜设置约束边缘构件
- **M-2.16** 短肢剪力墙（截面厚度不大于 300、且各肢截面高度与厚度之比的最大值大于 4 但不大于 8 的剪力墙）：抗震设计时底部加强部位墙厚 ≥ 200，其他部位 ≥ 180；轴压比限值一、二、三级分别 ≤ 0.45、0.50、0.55，一字形截面短肢剪力墙相应减少 0.1；不宜采用一字形短肢剪力墙，不宜在一字形短肢剪力墙上布置平面外与之相交的单侧楼面梁
- **M-2.17** 短肢剪力墙的布置限制：抗震设计时高层建筑结构不应全部采用短肢剪力墙；B 级高度高层建筑以及 9 度 A 级高度高层建筑不宜布置短肢剪力墙，不应采用具有较多短肢剪力墙的结构（短肢剪力墙承担的底部倾覆力矩 ≥ 结构底部总地震倾覆力矩的 30%）；短肢剪力墙承担的底部倾覆力矩 ≤ 结构底部总地震倾覆力矩的 50%

**R — Recommended（宜）**
- **R-2.1** 核心筒宜贯通建筑物全高，竖向刚度宜均匀变化
- **R-2.2** 核心筒宜布置在建筑平面中部，并在两个方向对称布置；核心筒平面宜居中于外框柱网
- **R-2.3** 核心筒常用平面尺寸：核心筒宽度宜取筒体总高的 1/10~1/12；外墙厚常用 200~300、内墙厚常用 160~250；底部加强部位墙厚宜比上部加厚 50~100（工程控制值）
- **R-2.4** 核心筒内宜设置内隔墙与结构楼板，将筒内空间分隔为电梯、楼梯、管道与设备空间；竖井除通风井、送风井、排烟井、必须通风的燃气管道竖井等特殊竖井外，宜在每层楼板处作防火分隔（GB 55037-2022 6.3.3）；内隔墙宜与核心筒墙整浇
- **R-2.5** 核心筒连梁宜与楼盖主梁、框架梁一次整浇，避免在连梁上二次叠合
- **R-2.6** 内筒偏置且结构平面长宽比 > 2 时，宜采用框架-双筒结构

**F — Forbidden（禁）**
- **F-2.1** 核心筒宽度 < 筒体总高的 1/12，且未设角筒、剪力墙或其他增强整体刚度的构件
- **F-2.2** 核心筒在外墙厚 < 200 或内墙厚 < 160 时继续加高建筑
- **F-2.3** 筒角开洞且筒角内壁至洞口距离 < 500 或小于开洞墙厚
- **F-2.4** 核心筒外墙水平方向连续开洞，或洞间墙肢截面高度 < 1200
- **F-2.5** 核心筒外墙与外框柱中距 > 12000（抗震）或 15000（非抗震）而未增设内柱
- **F-2.6** 核心筒在上部楼层截断或转换而未做加强，造成竖向刚度突变
- **F-2.7** 核心筒连梁跨高比 ≤ 1 而未设交叉暗撑，或交叉暗撑连梁截面宽度 < 400
- **F-2.8** 楼盖主梁搁置在核心筒连梁上
- **F-2.9** 内筒偏置且长宽比 > 2 而不采用框架-双筒结构，也不按 M-2.14 控制扭转

## 3 外围框架、连系梁与转换

**M — Mandatory（应）**
- **M-3.1** 框架-核心筒结构的周边柱间必须设置框架梁，形成闭合的周边框架
- **M-3.2** 框架柱距 ≤ 8400；取 100 整数倍，优选 600 模数（4200/5400/6000/7200/8400）；相邻柱距比 ≤ 1.2
- **M-3.3** 框架柱截面：抗震 b ≥ 350、h ≥ 400；非抗震 ≥ 300×300；b/h ≥ 0.7；柱净高与截面高度之比 H_n/h_c ≥ 3（避免短柱）；长细比 λ = H_0/h_c ≤ 25（抗震）/30（非抗震）
- **M-3.4** 框架梁：主梁 h = l_0/10~12（控制 l_0/h ≤ 12，抗震取 ≤ 10）；次梁 l_0/12~15；高宽比 h/b ≤ 4；主梁截面高 ≥ 400（跨度 ≥ 6000）、次梁 ≥ 200、一般 ≥ 250
- **M-3.5** 相邻层柱不贯通时，应设置转换梁等转换构件；转换构件的抗震等级按部分框支剪力墙结构中的框支框架采用
- **M-3.6** 框架柱轴压比限值按框架-剪力墙结构的规定采用（筒体结构中框架柱剪力远小于纯框架，剪跨比明显增大，限值可较纯框架适当放松）
- **M-3.7** 框架梁、柱与核心筒墙的中线宜重合；主体结构构件之间除个别节点外不应采用铰接
- **M-3.8** 转换层：转换层上下的结构质量中心宜接近重合；转换层位于第 1、2 层时，转换层下部与上部结构等效侧向刚度比抗震设计 ≥ 0.8、非抗震 ≥ 0.5，等效剪切刚度比抗震 ≥ 0.5、非抗震 ≥ 0.4；转换层位于第 2 层以上时，按楼层侧向刚度比计算的该比值 ≥ 0.6；转换层楼盖不应有大洞口，在平面内宜接近刚性；转换层楼盖与筒体、抗震墙应有可靠的连接；厚板转换层不宜用于 7 度及 7 度以上的高层建筑；9 度时不应采用转换层结构
- **M-3.9** 转换构件尺寸：转换梁截面高度 ≥ 计算跨度的 1/8；托柱转换梁截面宽度 ≥ 其上所托柱在梁宽方向的截面宽度；转换柱截面宽度非抗震 ≥ 400、抗震 ≥ 450；转换柱截面高度非抗震 ≥ 转换梁跨度的 1/15、抗震 ≥ 转换梁跨度的 1/12
- **M-3.10** 带托柱转换层的筒体结构，外围转换柱与内筒、核心筒外墙的中距 ≤ 12000

**R — Recommended（宜）**
- **R-3.1** 外围框架柱距常用 6000~8400；框架梁截面高常用 600~800，翼缘宽 ≤ 4b（工程控制值）
- **R-3.2** 核心筒与外围框架之间的第一排框架柱宜与核心筒墙肢对位；柱轴线与核心筒外墙轴线偏移 ≤ 50（工程控制值）
- **R-3.3** 核心筒与外围框架交接处宜设连系梁或构造连系构件，连系梁截面高不宜小于 400、跨度不宜大于 9000（工程控制值）
- **R-3.4** 外围框架宜与核心筒共同形成空间受力体系；单侧布置核心筒（内筒偏置）时宜控制扭转

**F — Forbidden（禁）**
- **F-3.1** 周边柱间不设框架梁
- **F-3.2** 核心筒与外围框架之间仅有楼板连接而无连系梁或整体连接措施
- **F-3.3** 框架柱距 > 8400 而不加高梁
- **F-3.4** 上下层框架柱截面突变 > 25%
- **F-3.5** 转换层上下层侧向刚度比 > 2，或转换层楼盖开大洞口、楼盖与筒体无可靠连接
- **F-3.6** 7 度及 7 度以上的高层建筑采用厚板转换层；9 度采用转换层结构
- **F-3.7** 转换梁截面高度 < 计算跨度的 1/8，或转换柱截面宽度 < 450（抗震）

## 4 楼盖与板

**M — Mandatory（应）**
- **M-4.1** 房屋高度 > 50000 时，框架-核心筒结构应采用现浇楼盖结构
- **M-4.2** 楼板厚度：一般楼层现浇 ≥ 80，板内预埋暗管时 ≥ 100；顶层 ≥ 120；普通地下室顶板 ≥ 160；作为上部结构嵌固部位的地下室楼层顶楼盖应采用梁板结构、楼板厚度 ≥ 180
- **M-4.3** 现浇楼盖：房屋的顶层、结构转换层、大底盘多塔楼结构的底盘顶层、平面复杂或开洞过大的楼层、作为上部结构嵌固部位的地下室楼层应采用现浇楼盖
- **M-4.4** 板跨厚比：单向 ≥ l_0/30；双向 ≥ l_0/40（常用 l_0/35~45）；悬挑根部 ≥ l_0/10~12
- **M-4.5** 最小板厚：卧室起居室 ≥ 80、厨卫 ≥ 100、走廊 ≥ 80、楼梯间 ≥ 100、屋面 ≥ 100、阳台 ≥ 80
- **M-4.6** 核心筒内楼板开洞：双筒间楼板开洞时，有效楼板宽度 ≥ 楼板典型宽度的 50%，洞口附近楼板应加厚
- **M-4.7** 现浇预应力混凝土楼板厚度可按跨度的 1/45~1/50 采用，且不宜小于 150

**R — Recommended（宜）**
- **R-4.1** 常用板厚：一般层 100~150，核心筒相邻跨及洞口周边 120~200，嵌固部位地下室顶板 200~250（工程控制值）
- **R-4.2** 核心筒内宜在每层楼板处作防火分隔；筒内结构楼板厚度不宜小于 100（工程控制值），降板处板厚 ≥ 100
- **R-4.3** 核心筒洞口周边宜加厚并设置边梁，边梁宽度 ≥ 2 倍板厚（工程控制值）

**F — Forbidden（禁）**
- **F-4.1** 房屋高度 > 50000 仍采用非现浇楼盖
- **F-4.2** 楼板厚度低于 M-4.2 或 M-4.5 的限值
- **F-4.3** 板跨厚比低于 M-4.4
- **F-4.4** 双筒间楼板开洞后有效楼板宽度 < 楼板典型宽度的 50%

## 5 缝与基础

**M — Mandatory（应）**
- **M-5.1** 伸缩缝最大间距：现浇结构按框架结构（室内 55000、露天 35000）与剪力墙结构（室内 45000、露天 30000）之间的数值取值；屋面无保温隔热措施时按露天栏数值取用；屋面无保温隔热、混凝土收缩较大或室内结构外露时间较长时应适当减小
- **M-5.2** 防震缝宽度：框架房屋高度 ≤ 15000 时 ≥ 100；超过 15000 时，6、7、8、9 度分别每增加高度 5000/4000/3000/2000 宜加宽 20；框架-核心筒按框架-剪力墙结构取框架数值的 70%，且不宜小于 100；两侧体系不同时按不利者定，两侧高度不同时按较低者定
- **M-5.3** 伸缩缝、沉降缝宽度按 M-5.2 关于防震缝宽度的要求
- **M-5.4** 后浇带：间距 ≤ 40000、带宽 800~1000、龄期 ≥ 60 d
- **M-5.5** 沉降缝最大间距 ≤ 30000；缝宽 ≥ 30~50；缝两侧留 ≥ 100 净距
- **M-5.6** 防震缝宜沿房屋全高设置；地下室、基础可不设缝，但与上部防震缝对应处应加强构造与连接；结构单元之间或主楼与裙房之间不宜采用牛腿托梁的做法设置防震缝
- **M-5.7** 基础：基础埋深天然地基或复合地基可取房屋高度的 1/15，桩基础（不计桩长）可取房屋高度的 1/18，且 ≥ 1000；承台厚 ≥ 400（桩基 ≥ 800、端承桩 ≥ 1000）；垫层厚 100；柱边至承台边 ≥ 50；基础梁 h ≥ 400、b ≥ 300，基础长宽比 ≤ 1.5
- **M-5.8** 基础底面零应力区：高宽比 > 4 的高层建筑不宜出现零应力区；高宽比 ≤ 4 时零应力区面积 ≤ 基础底面面积的 15%
- **M-5.9** 核心筒基础宜整体承台，核心筒墙体下的承台宜连通，避免核心筒与外围框架基础刚度突变；核心筒下可适当加密布桩

**R — Recommended（宜）**
- **R-5.1** 核心筒基础宜采用整体筏板或桩筏；筏板厚度常用 800~1500，基础埋深常用 1500~3000（工程控制值）
- **R-5.2** 沉降缝宜优先以后浇带替代，以保持外立面与地下防水连续

**F — Forbidden（禁）**
- **F-5.1** 伸缩缝间距超过 M-5.1 且未设后浇带
- **F-5.2** 防震缝宽度 < 100
- **F-5.3** 防震缝两侧共用柱，或缝边至柱边 < 100
- **F-5.4** 缝两侧刚度悬殊，或缝设在结构悬挑端
