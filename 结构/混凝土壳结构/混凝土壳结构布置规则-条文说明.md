# 1 壳型与几何判别

### M-1.1~M-1.6 壳体几何判别与矢高限值
- **M-1.1** 薄壳判别 t/R_min ≤ 1/20。**依据**：JGJ 22-2012 第 2.1.7 条（术语定义）。**要点**：厚度与中曲面最小曲率半径之比。**取值逻辑**：超过 1/20 即不再属于薄壳，薄膜理论不再适用。**不满足的后果**：分析模型与实际受力不符。**应用提示**：本条为分类判据，非强制设计要求。
- **M-1.2** 扁壳判别 f/L_min ≤ 1/5。**依据**：JGJ 22-2012 第 2.1.8 条。**取值逻辑**：矢跨比超过 1/5 时壳面弯曲效应显著，不能按扁壳理论。**不满足的后果**：内力与变形计算偏差。
- **M-1.3** 双曲扁壳矢高 ≤ 底面最小边长 1/5。**依据**：JGJ 22-2012 第 6.1.1 条。**取值逻辑**：保证扁壳假定成立。**不满足的后果**：需改用一般壳体分析。**应用提示**：与 M-1.2 同一判据的不同表达。
- **M-1.4** 圆柱面壳壳板矢高 ≥ B/8。**依据**：JGJ 22-2012 第 7.1.3 条。**要点**：B 为两直线边梁间水平距离。**取值逻辑**：矢高过小则壳面近乎平板、拱效应不足。**不满足的后果**：壳板弯矩增大、边梁受力不利。
- **M-1.5** 长壳壳体矢高 ≥ L/15。**依据**：JGJ 22-2012 第 7.1.3 条。**要点**：L 为横隔间距。**取值逻辑**：保证长壳整体拱效应。**不满足的后果**：壳体刚度不足。
- **M-1.6** 扭壳按扁壳理论条件：最大矢高 ≤ 矩形底面较小边长 1/5。**依据**：JGJ 22-2012 第 8.2.3 条。**取值逻辑**：超限时按一般扭壳分析。**不满足的后果**：内力计算模型失真。

### R-1.1~R-1.6 几何选型值
- **R-1.1** 底面长宽比 < 2。**依据**：JGJ 22-2012 第 3.1.4 条。**取值逻辑**：长宽比过大时长短向受力差异显著、边缘构件受力不均。**不满足的后果**：壳面开裂与边缘构件变形过大。**应用提示**：条文以"宜"表述，归 R。
- **R-1.2** 膜型扁壳尺寸上限 8000/10000。**依据**：JGJ 22-2012 第 3.1.5 条。**取值逻辑**：荷载分布变化与膜型受力假定在大尺寸下不易满足。**不满足的后果**：膜型假定失效。**应用提示**："不宜采用"，归 R。
- **R-1.3** 膜型扁壳矢高取值。**依据**：JGJ 22-2012 第 9.1.4 条。**取值逻辑**：矩形按对角线、圆形按直径取比例，与 R-1.2 的尺寸上限配套。
- **R-1.4** 不等曲率比 ≤ 2。**依据**：JGJ 22-2012 第 6.1.1 条。**取值逻辑**：两方向曲率差异过大使受力趋于单向。**应用提示**：归 R。
- **R-1.5** 曲率半径跨比 R_s/L ≤ 0.2 或 ≥ 4 的分类。**依据**：JGJ 22-2012 第 7.1.4 条。**取值逻辑**：小比值按梁理论、大比值按拱或弧形桁架。**应用提示**：属分析模型判别，仅取其中的几何比值。
- **R-1.6** 相邻壳板计算宽度 L/5。**依据**：JGJ 22-2012 第 7.1.4 条第 2 款。**取值逻辑**：按拱计算时取边梁两侧一定宽度参与工作。

### F-1.1~F-1.3 几何禁用情形
- **F-1.1** 底面长宽比 ≥ 2。**依据**：对应 R-1.1（条文为"宜小于 2"）。**不满足的后果**：长短向受力失衡。**应用提示**：建筑平面确需突破时改选其他壳型。
- **F-1.2** 壳板矢高 < B/8。**依据**：对应 M-1.4。**不满足的后果**：拱效应不足。
- **F-1.3** 长壳壳体矢高 < L/15。**依据**：对应 M-1.5。**不满足的后果**：刚度不足。

# 2 壳板厚度与边缘构件

### M-2.1~M-2.10 壳厚、边梁与加厚
- **M-2.1** 壳板厚度 ≥ 50。**依据**：JGJ 22-2012 第 3.3.2 条。**取值逻辑**：保护层、施工与稳定要求共同决定下限。**不满足的后果**：施工困难、局部失稳。**应用提示**：常用值见 R-2.5。
- **M-2.2** 增厚过渡段 ≥ 5 倍厚度增加值。**依据**：JGJ 22-2012 第 3.3.2 条。**取值逻辑**：突变会造成边缘扰力集中。**不满足的后果**：壳板与边缘构件连接处开裂。
- **M-2.3** 带肋旋转壳肋间距 ≤ 3000、环肋 ≥ 3 圈、两向间距比 ≤ 2。**依据**：JGJ 22-2012 第 5.4.1 条。**取值逻辑**：肋间距过大壳板局部刚度不足。**不满足的后果**：壳板挠度与裂缝超限。**应用提示**：肋的配筋要求不收录。
- **M-2.4** 长壳边梁高度 ≥ L/30。**依据**：JGJ 22-2012 第 7.3.2 条第 1 款。**取值逻辑**：边梁约束壳板边缘，高度不足则约束失效。**不满足的后果**：边缘构件变形过大、壳板开裂。
- **M-2.5** 短壳边梁高度 ≥ L/15。**依据**：JGJ 22-2012 第 7.3.2 条第 2 款。**取值逻辑**：短壳跨小、边梁相对更厚。**不满足的后果**：同上。
- **M-2.6** 扭壳有集中荷载时厚度 ≥ 80。**依据**：JGJ 22-2012 第 8.1.3 条。**取值逻辑**：集中荷载局部冲切与弯曲要求更厚。**不满足的后果**：局部开裂或冲切破坏。
- **M-2.7** 扭壳根部增厚 ≥ t、范围 ≥ 20t 且 ≥ 短边 1/10。**依据**：JGJ 22-2012 第 8.1.4 条。**取值逻辑**：壳板与边缘构件连接处需平滑传力。**不满足的后果**：根部开裂。
- **M-2.8** 组合扭壳脊线加厚 ≥ 3t、范围 ≥ 20t 且 ≥ 短边 1/15。**依据**：JGJ 22-2012 第 8.4.3 条第 1 款。**要点**：适用于跨度 ≤ 24 m。**取值逻辑**：脊线为组合壳传力汇集处。**不满足的后果**：脊线开裂。
- **M-2.9** 跨度 > 24 m 组合扭壳十字拼接梁宽 ≥ 300、高 ≥ 4t。**依据**：JGJ 22-2012 第 8.4.3 条第 3 款。**取值逻辑**：大跨度时拼接处需更强的外部构件。**不满足的后果**：拼接处变形与裂缝集中。
- **M-2.10** 四角支承膜型扁壳边缘构件高度 ≥ 相应跨度 1/30。**依据**：JGJ 22-2012 第 9.4.3 条。**取值逻辑**：边缘构件约束壳板并保证四角传力。**不满足的后果**：边缘变形过大。

### R-2.1~R-2.5 边缘构件与常用厚度
- **R-2.1** 边缘增厚 2~3 倍。**依据**：JGJ 22-2012 第 3.3.2 条。**取值逻辑**：边缘扰力区需要额外厚度与刚度。**应用提示**：与 M-2.2 的过渡段长度配套。
- **R-2.2** 环梁支柱数 6/8/10/12/16/20/24。**依据**：JGJ 22-2012 第 5.5.3 条。**取值逻辑**：表列常用柱数，按跨度与建筑平面选用。**应用提示**：支柱间距由柱数与外环直径反推。
- **R-2.3** 外环梁雨篷挑出 ≤ 500。**依据**：JGJ 22-2012 第 5.6.5 条。**取值逻辑**：小挑出对环梁内力影响可忽略。**应用提示**：超过 500 应计入环梁计算。
- **R-2.4** 带肋双曲扁壳每向肋 ≥ 4 根、间距 ≤ 3000、两向比 ≤ 2。**依据**：JGJ 22-2012 第 6.5.1 条。**取值逻辑**：与 M-2.3 同类判据。
- **R-2.5** 壳板常用厚度 60~120。**依据**：工程控制值；JGJ 22-2012 仅给 ≥ 50 的下限。**取值逻辑**：按跨度、施工与稳定留余量。**应用提示**：不得作为 M。

### F-2.1~F-2.4 壳厚与边缘禁用情形
- **F-2.1** 壳板厚度 < 50。**依据**：对应 M-2.1。**不满足的后果**：施工与稳定不足。
- **F-2.2** 边梁高度低于 M-2.4 或 M-2.5。**依据**：对应 M-2.4、M-2.5。**不满足的后果**：边缘约束失效。
- **F-2.3** 过渡段 < 5 倍增厚值。**依据**：对应 M-2.2。**不满足的后果**：边缘扰力集中。
- **F-2.4** 扭壳根部变厚度范围不足。**依据**：对应 M-2.7。**不满足的后果**：根部开裂。

# 3 开洞控制

> 本章仅保留孔洞的几何尺寸与间距。JGJ 22-2012 第 3.6.2~3.6.5 条中关于加劲肋、十字形梁配筋的要求按铁律剔除，不写入本规则。

### M-3.1~M-3.4 孔洞净距与横撑
- **M-3.1** 孔洞距边缘构件净距 ≥ 2 倍孔径或较大边长。**依据**：JGJ 22-2012 第 3.6.5 条。**取值逻辑**：洞口削弱壳板并扰动边缘构件，需留足距离。**不满足的后果**：边缘构件受力复杂、洞口周边开裂。
- **M-3.2** 相邻孔洞净距 ≥ 3 倍较大孔洞尺寸。**依据**：JGJ 22-2012 第 3.6.5 条。**取值逻辑**：多孔削弱叠加，间距需更大。**不满足的后果**：孔间壳带开裂。
- **M-3.3** 长壳顶部通长孔横撑间距 2000~3000。**依据**：JGJ 22-2012 第 7.4.1 条第 1 款。**取值逻辑**：洞口切断壳面传力，需横撑维持整体工作。**不满足的后果**：洞口两侧壳板变形不协调。
- **M-3.4** 短壳天窗横撑间距 ≤ 2000。**依据**：JGJ 22-2012 第 7.4.1 条第 2 款。**要点**：适用条件为孔宽 < 4000 且 ≤ B/3。**取值逻辑**：短壳洞口相对尺度大，横撑更密。**不满足的后果**：天窗周边开裂。

### R-3.1~R-3.5 孔洞尺寸分档
- **R-3.1** 可免算开洞尺寸 ≤ 短边或直径 1/10。**依据**：JGJ 22-2012 第 3.6.1 条。**取值逻辑**：小孔对薄膜内力扰动可忽略。**应用提示**：还需满足 3.6.2~3.6.7 的其他条件。
- **R-3.2** 受压区孔洞 ≤ 2000 设加劲肋。**依据**：JGJ 22-2012 第 3.6.2 条。**取值逻辑**：受压区孔边需恢复传力路径。**应用提示**：配筋要求不收录。
- **R-3.3** 受压区孔洞 2000~3000 设十字形/井字形梁。**依据**：JGJ 22-2012 第 3.6.3 条。**取值逻辑**：孔洞更大时需梁系传力。**应用提示**：梁的配筋不收录。
- **R-3.4** 受拉区孔洞 ≤ 1000 按 R-3.3 处理。**依据**：JGJ 22-2012 第 3.6.4 条。**取值逻辑**：受拉区对洞口更敏感，限值减半。
- **R-3.5** 矩形孔长宽比 ≤ 2。**依据**：JGJ 22-2012 第 3.6.5 条。**取值逻辑**：狭长孔削弱集中。**应用提示**：归 R。

### F-3.1~F-3.3 开洞禁用情形
- **F-3.1** 壳两端 L/5 范围内开洞。**依据**：JGJ 22-2012 第 7.4.1 条第 4 款。**不满足的后果**：边缘扰力区被削弱、支座附近开裂。
- **F-3.2** 孔洞净距不足。**依据**：对应 M-3.1、M-3.2。**不满足的后果**：孔间壳带开裂。
- **F-3.3** 天窗孔超限而未专项设置横撑。**依据**：对应 M-3.4 的条件。**不满足的后果**：洞口周边变形过大。

# 4 抗震挠度与缝

### M-4.1~M-4.5 挠度、抗震分档与伸缩缝
- **M-4.1** 边缘构件挠度 L>7000 → ≤L/400；L≤7000 → ≤L/250。**依据**：JGJ 22-2012 第 3.2.11 条。**取值逻辑**：大跨度构件对变形更敏感，限值收紧。**不满足的后果**：边缘构件变形导致壳板开裂。
- **M-4.2** ≤7 度、周边支承且跨度 ≤ 24000 可不验算；> 24000 应水平验算。**依据**：JGJ 22-2012 第 3.2.8 条第 1 款。**取值逻辑**：24000 为抗震验算分界。**不满足的后果**：漏算水平地震作用。
- **M-4.3** 8/9 度各种薄壳均应水平与竖向验算。**依据**：JGJ 22-2012 第 3.2.8 条第 2 款。**取值逻辑**：高烈度薄壳竖向效应不可忽略。**不满足的后果**：竖向地震作用漏算。
- **M-4.4** 伸缩缝缝宽 ≥ 50。**依据**：JGJ 22-2012 第 3.7.1 条第 1 款。**取值逻辑**：保证温度变形与施工偏差空间。**不满足的后果**：缝两侧碰撞或壳面挤压开裂。
- **M-4.5** 锯齿形壳伸缩缝间距 ≤ 5~6 倍该方向跨度。**依据**：JGJ 22-2012 第 3.7.1 条第 2 款。**取值逻辑**：锯齿方向温度变形累积更快。**不满足的后果**：锯齿根部开裂。

### R-4.1~R-4.3 抗震与挠度工程值
- **R-4.1** 竖向地震作用标准值 10%/20%/15%。**依据**：JGJ 22-2012 第 3.2.8 条第 2 款。**要点**：8 度 10%、9 度 20%、0.3g 时 15%。**取值逻辑**：按烈度分档的简化取值。**应用提示**：与 M-4.2 的跨度条件联用。
- **R-4.2** 跨度 > 24000 宜用振型分解反应谱法。**依据**：JGJ 22-2012 第 3.2.8 条第 3 款。**取值逻辑**：大体量壳体高阶振型参与明显。**应用提示**：特别不规则壳尚应做时程分析补充计算。
- **R-4.3** 挠度预警值 ≤ L/500。**依据**：工程控制值。**取值逻辑**：在 M-4.1 基础上留余量。**应用提示**：不得作为 M。

### F-4.1~F-4.3 抗震与缝禁用情形
- **F-4.1** 挠度超出 M-4.1。**依据**：对应 M-4.1。**不满足的后果**：壳板与边缘构件开裂。
- **F-4.2** 缝宽 < 50。**依据**：对应 M-4.4。**不满足的后果**：缝失效。
- **F-4.3** 锯齿形壳缝间距超限。**依据**：对应 M-4.5。**不满足的后果**：温度裂缝。

# 5 预制壳板与附录

### M-5.1~M-5.8 预制壳板几何
- **M-5.1** 平板壳板沿曲线边长 ≤ 3000。**依据**：JGJ 22-2012 第 3.4.3 条。**取值逻辑**：平板近似曲面的误差随边长增大。**不满足的后果**：壳面几何失真、拼缝不齐。
- **M-5.2** 扁球壳环向 ≥ 8、经向 ≥ 4。**依据**：JGJ 22-2012 第 3.4.4 条第 1 款。**取值逻辑**：分块过少无法逼近球面。**不满足的后果**：几何偏差与拼缝应力集中。
- **M-5.3** 双曲扁壳与扭壳每边 ≥ 9。**依据**：JGJ 22-2012 第 3.4.4 条第 2 款。**取值逻辑**：负/正高斯曲率壳面分块需更密。**不满足的后果**：壳面近似误差大。
- **M-5.4** 圆柱面壳圆弧向 ≥ 7。**依据**：JGJ 22-2012 第 3.4.4 条第 3 款。**取值逻辑**：沿圆弧分块保证曲面精度。**应用提示**：与 M-5.1 的曲线边长限值联用。
- **M-5.5** 齿形槽口长度 ≤ 1200。**依据**：JGJ 22-2012 第 3.4.7 条。**取值逻辑**：槽口过长削弱预制构件。**不满足的后果**：连接边劈裂。
- **M-5.6** 加劲肋间距 ≤ 3000、预埋件间距 ≤ 1500。**依据**：JGJ 22-2012 第 3.4.7 条。**取值逻辑**：保证预制壳板整体性与连接可靠性。**应用提示**：条文中的焊接长度要求按铁律不收录。
- **M-5.7** 跨度 ≥ 24000 时肋预埋件设于上表面。**依据**：JGJ 22-2012 第 3.4.7 条第 2 款。**取值逻辑**：大跨度壳安装时上表面操作与受力更有利。**不满足的后果**：安装与受力不利。
- **M-5.8** 接缝上口宽度 30/50。**依据**：JGJ 22-2012 第 3.4.9 条第 1 款。**要点**：肋高 ≤ 100 → ≥ 30；肋高 > 100 → ≥ 50。**取值逻辑**：保证接缝浇筑密实。**不满足的后果**：接缝不密实、渗水与裂缝。

### R-5.1~R-5.3 预制构造工程值
- **R-5.1** 加劲肋高取边长 1/20~1/15。**依据**：JGJ 22-2012 第 3.4.5 条。**取值逻辑**：兼顾刚度与运输安装。**应用提示**：归 R。
- **R-5.2** 装配圆柱面壳纵向分段 1500~3000。**依据**：JGJ 22-2012 第 7.4.5 条第 2 款。**取值逻辑**：由制作、运输、安装条件决定。**应用提示**：归 R。
- **R-5.3** 预埋件间距 ≤ 1500。**依据**：JGJ 22-2012 第 3.4.10 条第 4 款。**取值逻辑**：与 M-5.6 同类控制。**应用提示**：归 R。

### F-5.1~F-5.3 预制禁用情形
- **F-5.1** 分块数低于 M-5.2~M-5.4。**依据**：对应各条。**不满足的后果**：壳面几何失真。
- **F-5.2** 平板壳板曲线边长 > 3000。**依据**：对应 M-5.1。**不满足的后果**：曲面近似误差大。
- **F-5.3** 接缝宽度不足。**依据**：对应 M-5.8。**不满足的后果**：接缝不密实。
