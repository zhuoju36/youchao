# 混凝土壳结构布置规则

默认单位 mm。跨度、矢高、曲率半径以 m 标注者除外。

**适用范围**：房屋与一般构筑物中现浇或装配整体式钢筋混凝土、预应力混凝土薄壳的布置控制，含圆形底旋转壳、双曲扁壳、圆柱面壳、双曲抛物面扭壳与膜型扁壳。现行规程为 JGJ 22-2012《钢筋混凝土薄壳结构设计规程》（非 JGJ/T 22-2012，非 89 版，替代 JGJ/T 22-98）。本规则只收录可量化的外部尺寸、间距、外轮廓尺寸与比值；开洞条文中的配筋部分、材料强度与构件内部构造按铁律剔除，不列入。与《混凝土拱结构布置规则.md》《钢拱结构布置规则.md》按结构类型分册；钢网壳几何见《钢网壳结构布置规则.md》。

## 1 壳型与几何判别

**M — Mandatory（应）**
- **M-1.1** 薄壳判别：壳板厚度与中曲面最小曲率半径之比 t/R_min ≤ 1/20
- **M-1.2** 扁壳判别：壳板矢高与最小跨度之比 f/L_min ≤ 1/5
- **M-1.3** 双曲扁壳壳板矢高与底面最小边长之比 ≤ 1/5
- **M-1.4** 圆柱面壳壳板矢高 f ≥ 宽度 B 的 1/8（B 为两直线边梁间的水平距离）
- **M-1.5** 长壳壳体矢高 f_tot ≥ 跨度 L 的 1/15（L 为横隔间距）
- **M-1.6** 双曲抛物面扭壳按扁壳理论计算时，最大矢高 ≤ 矩形底面较小边长的 1/5

**R — Recommended（宜）**
- **R-1.1** 周边支承的矩形底面双曲扁壳、双曲抛物面扭壳、膜型扁壳，底面长度与宽度之比 < 2
- **R-1.2** 膜型扁壳尺寸上限：矩形底面边长 ≤ 8000；圆形底面直径 ≤ 10000
- **R-1.3** 膜型扁壳矢高：矩形底面取对角线长的 1/8~1/12；圆形底面取直径的 1/5~1/10
- **R-1.4** 不等曲率双曲扁壳的较大曲率与较小曲率之比 ≤ 2
- **R-1.5** 圆柱面壳曲率半径跨比：R_s/L ≤ 0.2 按梁理论计算；R_s/L ≥ 4 按拱或弧形桁架计算
- **R-1.6** 按拱或弧形桁架计算时，边梁相邻壳板计算宽度取跨度 L 的 1/5

**F — Forbidden（禁）**
- **F-1.1** 矩形底面长宽比 ≥ 2（周边支承双曲扁壳、扭壳、膜型扁壳）
- **F-1.2** 圆柱面壳壳板矢高 < B/8
- **F-1.3** 长壳壳体矢高 < L/15

## 2 壳板厚度与边缘构件

**M — Mandatory（应）**
- **M-2.1** 壳板厚度 ≥ 50
- **M-2.2** 壳板增厚区过渡段长度 ≥ 5 倍厚度增加值
- **M-2.3** 带肋旋转壳肋间距 ≤ 3000、环向肋 ≥ 3 圈、两个方向肋间距之比 ≤ 2
- **M-2.4** 长壳边梁（形式Ⅰ/Ⅱ/Ⅲ）高度 ≥ 壳体跨度的 1/30
- **M-2.5** 短壳边梁（形式Ⅰ/Ⅱ/Ⅲ）高度 ≥ 壳体跨度的 1/15
- **M-2.6** 双曲抛物面扭壳有集中荷载作用时，壳板厚度 ≥ 80
- **M-2.7** 扭壳壳板与边缘构件连接处根部增厚 ≥ 壳板厚度 t，变厚度范围 ≥ 20t 且 ≥ 矩形短边边长的 1/10
- **M-2.8** 组合扭壳脊线加厚 ≥ 3t、加厚范围 ≥ 20t 且 ≥ 矩形短边边长的 1/15（跨度 ≤ 24 m）
- **M-2.9** 跨度 > 24 m 的组合扭壳十字拼接处设梁，梁宽 ≥ 300、梁高 ≥ 4t
- **M-2.10** 四角支承矩形底面膜型扁壳边缘构件截面高度 ≥ 相应跨度的 1/30

**R — Recommended（宜）**
- **R-2.1** 壳板接近边缘与支承构件部位增厚至中部厚度的 2~3 倍
- **R-2.2** 旋转壳外环梁柱支承常用支柱数 n = 6、8、10、12、16、20、24
- **R-2.3** 外环梁上雨篷挑出长度 ≤ 500 时，可不计入环梁内力
- **R-2.4** 带肋双曲扁壳每方向肋 ≥ 4 根、肋间距 ≤ 3000、两方向肋间距之比 ≤ 2
- **R-2.5** 壳板常用厚度 60~120（工程控制值）

**F — Forbidden（禁）**
- **F-2.1** 壳板厚度 < 50
- **F-2.2** 边梁高度低于 M-2.4 或 M-2.5
- **F-2.3** 增厚区过渡段长度 < 5 倍厚度增加值
- **F-2.4** 扭壳根部变厚度范围 < 20t 或 < 矩形短边的 1/10

## 3 开洞控制

**M — Mandatory（应）**
- **M-3.1** 孔洞边缘至边缘构件的净距 ≥ 2 倍孔洞直径或矩形孔较大边长
- **M-3.2** 相邻孔洞净距 ≥ 3 倍较大孔洞直径或较大边长
- **M-3.3** 圆柱面长壳顶部通长孔洞沿孔洞纵向每隔 2000~3000 设置一道横撑
- **M-3.4** 短壳天窗孔宽 < 4000 且 ≤ 壳体宽度 B 的 1/3 时，天窗孔内横撑间距 ≤ 2000

**R — Recommended（宜）**
- **R-3.1** 圆孔直径或矩形孔长边 ≤ 壳体短边长度或直径的 1/10 时，可不对开洞影响另行计算
- **R-3.2** 受压区孔洞直径或边长 ≤ 2000 时，洞口周边设加劲肋
- **R-3.3** 受压区孔洞直径或边长 2000~3000 时，洞口周边设十字形梁或井字形梁
- **R-3.4** 受拉区孔洞直径或边长 ≤ 1000 时，按 R-3.3 处理
- **R-3.5** 矩形孔长边与短边之比 ≤ 2

**F — Forbidden（禁）**
- **F-3.1** 在圆柱面壳两端跨度 L 的 1/5 范围内设置孔洞
- **F-3.2** 孔洞净距低于 M-3.1 或 M-3.2
- **F-3.3** 短壳天窗孔宽 ≥ 4000 或 > 壳体宽度 B 的 1/3 而未按专项分析设置横撑

## 4 抗震挠度与缝

**M — Mandatory（应）**
- **M-4.1** 边缘构件挠度：跨度 > 7000 时 ≤ L/400；跨度 ≤ 7000 时 ≤ L/250
- **M-4.2** 抗震设防烈度 ≤ 7 度时，周边支承且跨度 ≤ 24000 的薄壳可不进行抗震验算；跨度 > 24000 时应进行水平抗震验算
- **M-4.3** 抗震设防烈度 8 度或 9 度时，各种薄壳均应进行水平与竖向抗震验算
- **M-4.4** 薄壳伸缩缝缝宽 ≥ 50
- **M-4.5** 锯齿形薄壳沿锯齿方向的伸缩缝间距 ≤ 5~6 倍该方向跨度

**R — Recommended（宜）**
- **R-4.1** 跨度 ≤ 24000 的薄壳竖向地震作用标准值：8 度取重力荷载代表值的 10%、9 度取 20%；设计基本地震加速度 0.3g 时取 15%
- **R-4.2** 体型复杂、悬挑较大或跨度 > 24000 的薄壳，宜采用振型分解反应谱法进行抗震计算
- **R-4.3** 薄壳边缘构件挠度预警值 ≤ L/500（工程控制值）

**F — Forbidden（禁）**
- **F-4.1** 边缘构件挠度超出 M-4.1
- **F-4.2** 伸缩缝缝宽 < 50
- **F-4.3** 锯齿形壳伸缩缝间距 > 5~6 倍该方向跨度

## 5 预制壳板与附录

**M — Mandatory（应）**
- **M-5.1** 采用平板壳板时，壳板沿曲线边的边长 ≤ 3000
- **M-5.2** 预制扁球壳沿环向分块 ≥ 8 块、沿经向分块 ≥ 4 块
- **M-5.3** 预制双曲扁壳及双曲抛物面扭壳沿每边分块 ≥ 9 块
- **M-5.4** 预制圆柱面壳沿圆弧向分块 ≥ 7 块
- **M-5.5** 预制构件连接边的齿形槽口长度 ≤ 1200
- **M-5.6** 预制壳板加劲肋间距 ≤ 3000；采用预埋件连接时预埋件间距 ≤ 1500
- **M-5.7** 壳体跨度 ≥ 24000 时，肋的预埋件应设置在上表面
- **M-5.8** 混凝土接缝上口宽度：肋高 ≤ 100 时 ≥ 30；肋高 > 100 时 ≥ 50

**R — Recommended（宜）**
- **R-5.1** 预制壳板周边加劲肋高度取预制壳板边长的 1/20~1/15
- **R-5.2** 装配整体式圆柱面壳纵向分段长度 1500~3000
- **R-5.3** 不采用钢筋连接时，预制壳板上预埋件间距 ≤ 1500

**F — Forbidden（禁）**
- **F-5.1** 预制壳板分块数低于 M-5.2~M-5.4
- **F-5.2** 平板壳板沿曲线边长 > 3000
- **F-5.3** 混凝土接缝上口宽度低于 M-5.8

## 附录 A 几何量取值口径

| 量 | 符号 | 取法 |
|---|---|---|
| 圆柱面壳宽度 | B | 两直线边梁间的水平距离 |
| 圆柱面壳跨度 | L | 圆柱面壳横隔的间距 |
| 壳体跨度 | L | 边缘构件（边梁、环梁、横隔）支承点之间的距离 |
| 壳板厚度 | t | 壳板两曲面间的法线长度 |
| 壳板矢高 | f | 壳板中曲面最高处到壳板底平面的最大竖直距离 |
| 壳体矢高 | f_tot | 壳板中曲面最高处到壳体底平面的最大竖直距离 |
| 拱轴线长度 | L_a | 仅用于《混凝土拱结构布置规则.md》 |
