# 一般游泳馆布置规则 修订记录

配套文件：《一般游泳馆布置规则.md》（条文）、《一般游泳馆布置规则-条文说明.md》（条文说明）。

| 版本 | 变更 |
|---|---|
| 2026-11-26 | 首次成文。依据 JGJ 31-2003 第 7、8 章，GB 55031-2022、GB 55037-2022、GB 55019-2021、GB 37488-2019、GB 37489.3-2019、GB 19079.1-2013 建立条文与条文说明，编号体系 `M/R/F-章.条`，共 5 章。 |
| 2026-11-26 | 适用范围界定为公共游泳馆，含比赛池、训练池、热身池、健身池、儿童池及配套用房；住宅私家泳池、水上乐园滑道池、温泉 SPA 池不适用。竞技等级与非竞技水面面积分档两套口径分列，不混用。 |
| 2026-11-26 | 池体尺寸按 JGJ 31-2003 第 7.2 节写入：比赛池 50 000／25 000、泳道 2 500、池岸分档、出发台 ≥500×500 且前缘高出水面 500~750、握手器 300~600、攀梯 ≥4 个、触板露 300 浸 600；水球、花游、跳水池按专项池型列条。 |
| 2026-11-26 | 公共卫生底线按 GB 37489.3-2019 与 GB 19079.1-2013 写入：人均池水面积 ≥2.5 m²/人、更衣柜 A=S/2.5、淋浴每 20~30 人 1 个、浸脚池长 ≥2 000 深 ≥200、儿童池水深 ≤800、浅水区 ≤1 200、湿润状态静摩擦系数 ≥0.5。 |
| 2026-11-26 | 儿童池与成人池不连通、分设独立循环系统列为 M/F；具体循环参数转《一般游泳馆给排水布置规则.md》，避免两本规则重复。 |
| 2026-11-26 | 防火按 GB 55037-2022 第 4.3.16、7.4.6、5.5.18 条，疏散按 JGJ 31-2003 第 8.2 节；JGJ 31 原引用的已废止防火规范一律替换为现行全文强制规范。 |
| 2026-11-26 | 无障碍按 GB 55019-2021 第 2、3 章重写：通道净宽 1 200／人员密集 1 800、坡道 1:12、厕位 1 800×1 500、淋浴短边 1 500、轮椅席位 1 300×800 且陪护 1:1。 |
| 2026-11-26 | 规范版本核对：JGJ 31-2003 现行但原引用标准已更新；GB 19079.1-2013 修订中；GB/T 22517.2-2024 正式文本未获取；泳池水面不计入防火分区面积与泳池上空免设自动灭火均无可靠现行国标依据，列待确认、不写入条文。 |
| 2026-11-26 | 体例统一：文内重复的「编号规则」小节按 README 已给出统一说明的要求整体移除，条文仅保留规则正文。 |
