# 有巢 — 用于指导智能体的建筑布局规则集

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

*Youchao · Building Layout Rules for Agents*

> 昔载上世，人固多难，有圣人者，教之巢居，冬则营窟，夏则居巢。 未有火化，搏兽而食，凿井而饮。 桧秸以为蓐，以辟其难。 而人说之，使王天下，号曰有巢氏

本项目面向智能体的建筑布置规则集：把可量化的布置经验写成「应 / 宜 / 禁」条文，供智能体设计布置时直接查用。

本项目收录各种定量、显性、清晰、客观可评估的规则供智能体参考，尽可能排除定性、隐性、模糊、带有主观偏好的概念或个人主张。

## 编号规则

每本规则中的所有编号遵照以下规则，不得擅自改动。两本规则中条文编号可相同，但同一本规则中条文编号不得重复。

| 前缀 | 含义 | 说明 |
|---|---|---|
| M | Mandatory（应） | 规范/强制要求，须满足 |
| R | Recommended（宜） | 工程常用经验值，可按实际情况调整 |
| F | Forbidden（禁） | 不得出现的做法 |

编号形式：`类别-章.条`，必要时再加 `.款`，即二级如 `M-x.y`、三级如 `M-x.y.z`；编号全局唯一，可直接引用。

## 使用

1. 默认只读「布置规则.md」条文；
2. 需权衡限值、核对规范依据时再读「条文说明.md」；
3. 改动规则须同步「修订记录.md」。

用户可以fork，并根据需要自行编写符合习惯的规则，指导自己的智能体进行设计布置

编写与编号细则见 [AGENTS.md](AGENTS.md)。
