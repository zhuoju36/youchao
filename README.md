# BLR — Building Layout Rule

面向智能体的建筑布置规则库：把可量化的布置经验写成「应 / 宜 / 禁」条文，供智能体设计布置时直接查用。

## 内容

| 专业 | 已有规则 |
|---|---|
| 结构 | 一般混凝土框架结构、一般混凝土框架-剪力墙结构、一般混凝土剪力墙结构、一般混凝土框架-核心筒结构 |
| 建筑 / 给排水 / 暖通 / 电气 | 规划中 |

## 目录

```
BLR/
├── AGENTS.md                    # 编写规范，先读
└── 结构/<结构体系>/
    ├── <体系>布置规则.md          # 条文（默认读这本）
    ├── <体系>布置规则-条文说明.md  # 依据、取值逻辑、不满足的后果
    └── 修订记录.md
```

## 编号规则

每本规则中的所有编号遵照以下规则，不得擅自改动。两本规则中条文编号可相同，但同一本规则中条文编号不得重复。

| 前缀 | 含义 | 说明 |
|---|---|---|
| M | Mandatory（应） | 规范/强制要求，须满足 |
| R | Recommended（宜） | 工程常用经验值，可按实际情况调整 |
| F | Forbidden（禁） | 不得出现的做法 |

编号形式：`类别-章.条`，必要时再加 `.款`，即二级如 `M-x.y`、三级如 `M-x.y.z`；编号全局唯一，可直接引用。

## 使用

1. 默认只读「布置规则.md」条文；
2. 需权衡限值、核对规范依据时再读「条文说明.md」；
3. 改动规则须同步「修订记录.md」。

用户可以fork，根据需要自行编写符合习惯的规则，指导自己的智能体进行设计布置

编写与编号细则见 [AGENTS.md](AGENTS.md)。
