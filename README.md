# BLR — Building Layout Rule

面向智能体的建筑布置规则库：把可量化的布置经验写成「应 / 宜 / 禁」条文，供智能体设计布置时直接查用。

## 内容

| 专业 | 已有规则 |
|---|---|
| 结构 | 一般混凝土框架结构、一般混凝土框架-剪力墙结构、一般混凝土剪力墙结构、一般混凝土框架-核心筒结构 |
| 建筑 / 给排水 / 暖通 / 电气 | 规划中 |

## 目录

```
BLR/
├── AGENTS.md                    # 编写规范，先读
└── 结构/<结构体系>/
    ├── <体系>布置原则.md          # 条文（默认读这本）
    ├── <体系>布置原则-条文说明.md  # 依据、取值逻辑、不满足的后果
    └── 修订记录.md
```

## 规则体系

- 三类：**M** 应（强制）/ **R** 宜（工程经验值）/ **F** 禁
- 编号 `M-1.1`，可加款 `M-1.1.1`，同一本规则内唯一，可直接引用
- 只写定量尺寸（间距、外轮廓等），默认单位 mm；不写配筋、材料等构件内部信息，也不写定性、模糊的要求

## 使用

1. 默认只读「布置原则.md」条文；
2. 需权衡限值、核对规范依据时再读「条文说明.md」；
3. 改动规则须同步「修订记录.md」。

用户可以fork，根据需要自行编写符合习惯的规则，指导自己的智能体进行设计布置

编写与编号细则见 [AGENTS.md](AGENTS.md)。
