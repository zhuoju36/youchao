# 高层住宅暖通布置规则 修订记录

配套文件：《高层住宅暖通布置规则.md》（条文）、《高层住宅暖通布置规则-条文说明.md》（条文说明）。

| 版本 | 变更 |
|---|---|
| 2026-11-26 | 首次成文。依据 GB 55038-2025、GB 55015-2021、GB 55037-2022、GB 55031-2022、GB 50736-2012、GB 50016-2014（2018 年版）、GB 51251-2017、GB 50243-2016、GB 50352-2019 建立条文与条文说明，编号体系 `M/R/F-章.条`，共 8 章。 |
| 2026-11-26 | 适用范围界定为建筑高度 > 27 000 的住宅，含 > 100 000 的超高层住宅；≤ 27 000 转《住宅暖通布置规则.md》；住宅底部商业服务网点按公共建筑执行。 |
| 2026-11-26 | 防烟触发条件按 GB 51251-2017 第 3.1.2 条：建筑高度 > 100 000 的住宅，防烟楼梯间、独立/共用/合用前室及消防电梯前室应采用机械加压送风；> 100 000 时系统竖向分段，每段 ≤ 100 000（第 3.3.1 条）。 |
| 2026-11-26 | 余压按 GB 51251-2017 第 3.4.4 条：前室、封闭避难层（间）与走道 25~30，楼梯间与走道 40~50；设计风量 ≥ 计算风量 1.2 倍；送风口 ≤ 7、金属风管 ≤ 20、非金属风管 ≤ 15。 |
| 2026-11-26 | 初稿把"剪刀楼梯两个楼梯间及前室分别独立设置加压送风"列为 R，复核 GB 51251-2017 第 3.1.5 条第 3 款为强制性条文后，改为 M-5.12。 |
| 2026-11-26 | 补入合用前室的独立加压送风要求：楼梯间与合用前室应分别独立设置系统，依据 GB 51251-2017 第 3.1.5 条第 2 款，列为 M-5.13。 |
| 2026-11-26 | 初稿把"建筑高度 ≤ 100 000 住宅楼梯间可不设防烟系统的条件"列为 R，复核 GB 50016-2014（2018 年版）第 8.5.1 条后改为 M-1.9，明确属于"可不设"的许可条件。 |
| 2026-11-26 | 排烟按 GB 51251-2017 补入：防烟分区按净高分三档；储烟仓自然 ≥ 20%/机械 ≥ 10% 且 ≥ 500；排烟口至最远点 ≤ 30 000、距可燃物 ≥ 1 500；补风口与排烟口同分区水平 ≥ 5 000；排烟防火阀距墙端面 ≤ 200。 |
| 2026-11-26 | 分体式空调室外机位按 GB 55038-2025 第 7.2 节：可上人专用平台板、结构同设计年限、坐式安装、防坠落、格栅不妨碍散热；净宽 900、净深 350 为工程控制值。 |
| 2026-11-26 | 避难层（间）按 GB 51251-2017 第 3.2.3、3.4.3 条：自然通风不同朝向开口 ≥ 地面面积 2% 且每朝向 ≥ 2.0 m²；机械加压送风 ≥ 30 m³/(m²·h)。 |
| 2026-11-26 | 调试按 GB 55015-2021 第 6.3.13 条与 GB 51251-2017 第 8 章：除风量、流量偏差外，增加余压、排烟风速与补风量实测。 |
| 2026-11-26 | 新增附录《高层与住宅的差异口径》，列示防烟、排烟、室外机位、竖向系统与调试五项差异；新增常用控制值速查表。 |
| 2026-11-26 | 体例统一：文内重复的「编号规则」小节按 README 已给出统一说明的要求整体移除，条文仅保留规则正文。 |
