# 一般住宅暖通布置规则 修订记录

配套文件：《一般住宅暖通布置规则.md》（条文）、《一般住宅暖通布置规则-条文说明.md》（条文说明）。

| 版本 | 变更 |
|---|---|
| 2026-11-26 | 首次成文。依据 GB 55038-2025、GB 55015-2021、GB 55037-2022、GB 55031-2022、GB 50736-2012、GB 50016-2014（2018 年版）、GB 51251-2017、GB 50243-2016、GB 50242-2002 建立条文与条文说明，编号体系 `M/R/F-章.条`，共 7 章。 |
| 2026-11-26 | 适用范围界定为建筑高度 ≤ 27 000 的成套住宅；别墅、联排住宅、宿舍、旅馆式公寓、老年照料设施、办公与商业建筑不适用；> 27 000 的住宅转《高层住宅暖通布置规则.md》。 |
| 2026-11-26 | 强制性来源统一：气候区供暖空调设置、集中供暖室温 18/15 与热水热媒、自然通风开口 5%/10%/0.60 m²、公共空间总立管、暗卫生间防回流机械通风、冷凝水有组织排放，一律引 GB 55038-2025。 |
| 2026-11-26 | 冷凝水坡度按 GB 50736-2012 第 8.5.23 条拆分：泄水支管 ≥ 0.010；干管宜 ≥ 0.005、最小 ≥ 0.003。避免把"不宜"误写成强制下限。 |
| 2026-11-26 | 防火阀距防火分隔墙面 200 未标为通用强条：GB 50016-2014（2018 年版）第 9.3.13 条只要求"宜靠近"，200 的明确出处是 GB 51251-2017 第 6.4.1 条（排烟防火阀），故仅列 R-5.4 工程控制值。 |
| 2026-11-26 | 分体式空调室外机位按 GB 55038-2025 第 7.2 节编写，不标具体条号，待正式核对公布版条文编号后补齐；净宽 900、净深 350 标为工程控制值，与《一般住宅布置规则》M-6.6 协调。 |
| 2026-11-26 | 排烟部分只引用 GB 50016 第 8.5.3 条第 5 款（走道 > 20 000）与第 8.5.4 条（地下/无窗房间），不套用公共建筑房间 100/300 m² 条款。 |
| 2026-11-26 | 新增附录《常用控制值速查》，逐项列示自然通风开口、供暖室温、换气次数、事故通风、冷凝水坡度、防火阀、排烟口、防烟分区、储烟仓与风量偏差的出处。 |
