# 游泳馆给排水布置规则 修订记录

配套文件：《游泳馆给排水布置规则.md》（条文）、《游泳馆给排水布置规则-条文说明.md》（条文说明）。

| 版本 | 变更 |
|---|---|
| 2026-11-26 | 首次成文。依据 CJJ 122-2017 第 3~7、12~14 章，GB 55020-2021、GB 55036-2022、GB 55037-2022、GB 37489.3-2019、GB 37488-2019、CJ/T 244-2016、GB 50974-2014 建立条文与条文说明，编号体系 `M/R/F-章.条`，共 6 章。 |
| 2026-11-26 | 适用范围界定为公共游泳馆池水循环净化、给排水、消毒、加热、池岸冲洗与消防给排水；建筑布置指标转《游泳馆布置规则.md》；住宅私家泳池、水上乐园滑道池、温泉 SPA 池不适用。 |
| 2026-11-26 | 强制性底线按 GB 55020-2021 与 CJJ 122-2017 原强条写入：循环给水与独立系统、必须消毒、水质平衡、氯剂禁直投、禁用氯气/液氯/二氧化氯/液态溴、顺流式紧急停泵按钮 ≤36 V、池底回水口 ≥2 个且孔缝 ≤8 mm、臭氧负压投加与联锁、发生器间报警器。 |
| 2026-11-26 | 池水水质按 GB 55020-2021 第 6.1.1 条与 CJ/T 244-2016 表 1 的较严值写入；GB 37488-2019 表 4 的卫生监督口径差异列待确认，不混写。 |
| 2026-11-26 | 循环周期采用 GB 37489.3-2019 第 7.3 条 ≤4 h 底线；CJJ 122-2017 表 4.4.1、表 3.3.1、表 3.4.2、表 5.4.2 为图片表且转录存在错位，未写入分档值，列待确认。 |
| 2026-11-26 | 水温口径冲突（开放条件 ≥26℃、卫生推荐 23~30℃、产品标准 20~30℃、设计按池型分档）列待确认；本规则只写推荐值并指向说明。 |
| 2026-11-26 | 泳池上空是否可免设自动灭火与火灾自动报警的依据为技术指南而非强制性国标，不写入条文，列待确认并注明向消防审图机构核实。 |
| 2026-11-26 | 消防按 GB 55036-2022 与 GB 50974-2014 写入消火栓间距、栓口动压、市政水源、消防泵人工停泵与灭火器配置；GB 50974 部分强条已废止，冲突时以 GB 55036 为准。 |
| 2026-11-26 | 体例统一：文内重复的「编号规则」小节按 README 已给出统一说明的要求整体移除，条文仅保留规则正文。 |
| 2026-11-27 | 名称统一：去掉名称前缀"一般"，文件夹、书名、文件名及全仓库交叉引用同步改为"游泳馆"。 |
