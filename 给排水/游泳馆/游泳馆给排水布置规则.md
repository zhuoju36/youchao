# 游泳馆给排水布置规则

默认单位 **mm**；压力单位 **MPa**；流量单位 **m³/h**（循环）、**L/s**（消防）；流速单位 **m/s**；温度单位 **℃**；时间单位 **h**、**min**；面积单位 **m²**；投加量单位 **mg/L**；照度单位 **lx**。

本规则适用于公共游泳馆池水循环净化、给水排水、消毒、加热、池岸冲洗与消防给排水布置，涵盖比赛池、训练池、热身池、健身池与儿童池。建筑布置指标见《游泳馆布置规则.md》。住宅私家泳池、水上乐园滑道池、温泉 SPA 池不适用。

本规则只收录定量布置指标（尺寸、间距、面积、压力、流量、流速、时间、温度、浓度）；条文依据、取值逻辑与不满足的后果见《游泳馆给排水布置规则-条文说明.md》。

## 1 总体控制

**M — Mandatory（应）**
- **M-1.1** 游泳池应采用循环给水并设置循环净化处理系统（CJJ 122-2017 第 4.1.1 条；GB 55020-2021 第 6.2.1 条）
- **M-1.2** 不同用途的池应各自设置独立循环系统；儿童池与成人池不得共用（CJJ 122-2017 第 4.1.3 条；GB 55020-2021 第 6.2.1 条；GB 37489.3-2019 第 6.1.2 条）
- **M-1.3** 循环净化系统必须设置消毒设施（CJJ 122-2017 第 6.1.1 条；GB 55020-2021 第 6.3.1 条）
- **M-1.4** 应采取水质平衡措施（GB 55020-2021 第 6.3.4 条）
- **M-1.5** 游泳池补水应计量，设补水计量专用水表（GB 37489.3-2019 第 7.1 节；CJJ 122-2017 第 3.4.3-4 条）
- **M-1.6** 池水水质：浑浊度 ≤ 0.5 NTU；pH 7.2~7.8；尿素 ≤ 3.5 mg/L；菌落总数 ≤ 100 CFU/mL；大肠菌群不得检出；余氯 0.3~1.0 mg/L（GB 55020-2021 第 6.1.1 条；CJ/T 244-2016 表 1，以正式文本为准）
- **M-1.7** 补水水质应符合 GB 5749（GB 55020-2021 第 3.1.2 条）

**F — Forbidden（禁）**
- **F-1.1** 游泳池消毒使用氯气、液氯、二氧化氯或液态溴（GB 55020-2021 第 6.3.2 条）
- **F-1.2** 消毒剂直接投入池水（CJJ 122-2017 第 6.3.3 条；GB 55020-2021 第 6.3.3 条）
- **F-1.3** 生活饮用水管道与中水、回用雨水管道连接（GB 55020-2021 第 3.1.4 条）

## 2 循环、过滤与水质控制

**M — Mandatory（应）**
- **M-2.1** 池水循环周期 ≤ 4 h（GB 37489.3-2019 第 7.3 条）；CJJ 122-2017 表 4.4.1 按池型分档取值（正式文本复核）
- **M-2.2** 混合流式循环的表面溢流回水量 ≥ 循环流量的 60%，池底回水量 ≤ 40%（CJJ 122-2017 第 4.3.3-1 条）
- **M-2.3** 循环水泵工作泵 ≥ 2 台并设备用泵；并联时扬程乘 1.05~1.10 系数（CJJ 122-2017 第 4.6.2-4 条）
- **M-2.4** 循环给水与回水管公称压力 ≥ 1.0 MPa（CJJ 122-2017 第 4.7.1-4 条）
- **M-2.5** 循环水流速：给水 1.5~2.5、回水 1.0~1.5、水泵吸水 0.7~1.2 m/s（CJJ 122-2017 第 4.7.2 条）
- **M-2.6** 顺流式循环应在救护员座位附近设紧急停泵按钮，电压 ≤ 36 V（CJJ 122-2017 第 4.3.4 条，原强制性条文）
- **M-2.7** 每台循环水泵吸水管上设毛发聚集器 1 个；滤筒孔眼总面积 ≥ 进水管截面 2 倍；孔眼 ≤ 3.0 mm 或网眼 ≤ 15 目；耐压 ≥ 0.40 MPa（CJJ 122-2017 第 5.3.1、5.3.2 条）
- **M-2.8** 过滤设备 ≥ 2 台，总过滤能力 ≥ 循环流量的 1.10 倍（CJJ 122-2017 第 5.2.2 条）
- **M-2.9** 压力过滤器：立式直径 ≤ 2.40 m；卧式直径 ≥ 2.20 m、过滤面积 ≤ 10.0 m²；工作压力 ≥ 系统压力的 1.5 倍（CJJ 122-2017 第 5.4.4 条）
- **M-2.10** 重力过滤器滤料层厚度 ≥ 700 mm；单层滤速 ≤ 10、多层滤速 ≤ 12 m/h（CJJ 122-2017 第 5.4.5 条）
- **M-2.11** 过滤器反冲洗排水不应与其他排水管道直接连接（CJJ 122-2017 第 5.4.3 条）

**R — Recommended（宜）**
- **R-2.1** 循环流量 Q = αp·V/T，其中 αp = 1.05~1.10（CJJ 122-2017 第 4.5.1 条）
- **R-2.2** 竞赛池、专用池、演出池宜采用逆流或混合流；公共池宜采用逆流或混合流；季节性室外池宜采用顺流（CJJ 122-2017 第 4.3.2 条）
- **R-2.3** 池水温度宜 23~30℃（GB 37488-2019 第 4.4.1.2 条；开放场所 ≥ 26℃ 的版本冲突见条文说明）

**F — Forbidden（禁）**
- **F-2.1** 池水循环周期 > 4 h
- **F-2.2** 顺流式循环未设紧急停泵按钮，或按钮电压 > 36 V
- **F-2.3** 反冲洗排水管与其他排水管直接连接

## 3 池体给水排水构造

**M — Mandatory（应）**
- **M-3.1** 池底给水口间距 ≤ 3 000；不规则池单口服务面积 ≤ 8.0 m²（CJJ 122-2017 第 4.9.2 条）
- **M-3.2** 池壁给水口间距 ≤ 3 000；池深 ≤ 2.0 m 时设在水面下 500~1 000；池深 > 2.5 m 时设上下两层、间距 ≤ 1 500，最低层高于池底 500（CJJ 122-2017 第 4.9.3 条）
- **M-3.3** 给水口流速：池壁 ≤ 1.0 m/s（儿童池、教学区 ≤ 0.5）；池底水深 ≤ 3.0 m 时 ≤ 0.5、> 3.0 m 时 ≤ 1.0 m/s（CJJ 122-2017 第 4.9.6 条）
- **M-3.4** 给水口喇叭口面积 ≥ 接管截面积 2 倍；格栅孔隙 ≤ 8 mm（CJJ 122-2017 第 4.9.7 条）
- **M-3.5** 溢流回水口接管直径 ≥ 50、间距 ≤ 3 000（CJJ 122-2017 第 4.10.1 条）
- **M-3.6** 池底回水口 ≥ 2 个、间距 ≥ 1 000；盖板孔缝 ≤ 8 mm、缝隙流速 ≤ 0.2 m/s（CJJ 122-2017 第 4.10.2 条，原强制性条文）
- **M-3.7** 泄水口 ≥ 2 个，池水泄空时间 ≤ 6 h（CJJ 122-2017 第 4.10.4、13.3.1 条）
- **M-3.8** 回水口、泄水口格栅表面积 ≥ 接管截面积 6 倍；开孔面积 ≤ 接管截面积的 30%（CJJ 122-2017 第 4.10.5 条）
- **M-3.9** 逆流式、混合流式溢流回水沟：标准池与跳水池宽 ≥ 300、深 ≥ 300；沟底坡度 ≥ 1%（CJJ 122-2017 第 4.11.1 条）
- **M-3.10** 顺流式溢水沟最小 300×300；排水口管径 ≥ 50、间距 ≤ 3 000、坡度 1%（CJJ 122-2017 第 4.11.2 条）
- **M-3.11** 溢水堰顶面标高误差 ≤ 2 mm（CJJ 122-2017 第 4.11.3-1 条）
- **M-3.12** 均衡水池最高水位低于溢流回水管管底 ≥ 300；均衡水池容积按每入池者排水量 0.06 m³/人计（CJJ 122-2017 第 4.8.1 条）
- **M-3.13** 顺流式平衡水池池内底低于池回水管管底 ≥ 700（CJJ 122-2017 第 4.8.2-5 条）
- **M-3.14** 补水水箱：单纯补水容积 ≥ 2.0 m³；兼回收溢流水时按循环流量 10% 计（CJJ 122-2017 第 4.12.2 条）
- **M-3.15** 池底配水管架空净高 ≥ 1 200；池长 ≤ 25 m 时垫层 ≥ 300、沟槽 ≥ 300×300；池长 > 25 m 时垫层 ≥ 500、沟槽 ≥ 500×500（CJJ 122-2017 第 4.7.4 条）

**F — Forbidden（禁）**
- **F-3.1** 池底回水口少于 2 个，或盖板孔缝 > 8 mm、缝隙流速 > 0.2 m/s
- **F-3.2** 溢水堰顶面标高误差 > 2 mm
- **F-3.3** 池底配水管架空净高 < 1 200

## 4 消毒、加热与机房

**M — Mandatory（应）**
- **M-4.1** 臭氧消毒投加量：全流量半程式 0.8~1.2 mg/L；分流量全程式 0.4~0.6 mg/L（分流比例 ≥ 25%）；池水余臭氧 ≤ 0.05 mg/L（CJJ 122-2017 第 6.2.2 条）
- **M-4.2** 水面上方 0.20 m 处空气中臭氧浓度 ≤ 0.20 mg/m³（CJJ 122-2017 第 6.2.3-1 条）
- **M-4.3** 臭氧接触时间 ≥ 2 min，传质系数 ≥ 90%（CJJ 122-2017 第 6.2.5、6.2.6 条）
- **M-4.4** 臭氧投加应采用负压投加、全自动控制，并与循环水泵联锁（GB 55020-2021 第 6.3.3 条；CJJ 122-2017 第 6.2.4 条，原强制性条文）
- **M-4.5** 加药间、药品库独立设置，采用独立分隔与独立进排风（CJJ 122-2017 第 14.1.2-2、14.5.1 条）
- **M-4.6** 发生器间报警器：距设备水平 1.0 m 内、地面上 0.3 m 至设备高度范围设臭氧报警器 1 个；每 20 m² 设氢气或氯气报警器 1 个；产氯量 > 50 g/h 时设独立管道引至室外（CJJ 122-2017 第 14.1.5 条，原强制性条文）
- **M-4.7** 药库、水处理机房事故排风 ≥ 12 次/h（GB 37489.3-2019 第 8.3 节）
- **M-4.8** 机房维修通道宽度为最大设备尺寸的 1.2 倍（CJJ 122-2017 第 14.1.2-4 条）
- **M-4.9** 设备基础高出机房地面 ≥ 0.10 m（CJJ 122-2017 第 14.1.3 条）
- **M-4.10** 机房温度 5~35℃、换气 ≥ 4 次/h、照度 ≥ 100 lx（CJJ 122-2017 第 14.1.4 条）

**R — Recommended（宜）**
- **R-4.1** 初次充水时间：竞赛池、专用池 ≤ 48 h；休闲池 ≤ 72 h（CJJ 122-2017 第 3.4.1 条）
- **R-4.2** 初次加热 24~48 h；钢筋混凝土池升温速率 ≤ 0.5℃/h（CJJ 122-2017 第 7.1.4 条）
- **R-4.3** 加热设备容量按计算负荷 1.1~1.2 倍配置，每池 ≥ 2 台（CJJ 122-2017 第 7.1.5 条）
- **R-4.4** 室内环境温度宜比设定池水温高 2℃ 且 ≤ 30℃（CJJ 122-2017 第 7.1.6 条）

## 5 池岸与辅助给排水

**M — Mandatory（应）**
- **M-5.1** 浸脚消毒池：长 ≥ 2 000、池深 ≥ 200、有效液深 ≥ 150；余氯 5~10 mg/L；每场次换水 1 次（CJJ 122-2017 第 12.1.1、12.1.2 条；GB 37489.3-2019 第 6.4 节）
- **M-5.2** 强制淋浴：淋浴排数 ≥ 3、排距 ≤ 800；顶喷 ≥ 3 只、侧喷每侧 ≥ 1 只；孔径 0.8 mm、孔距 ≤ 400；安装高度 ≥ 2 200；集水长度 ≥ 2 000；感应开启时间 ≤ 0.5 s、喷水时间 ≥ 6 s；水温 ≤ 38℃、压力 ≥ 0.15 MPa（CJJ 122-2017 第 12.2.2~12.2.4 条）
- **M-5.3** 池岸冲洗取水阀每侧 ≥ 2 只，直径 ≥ 25，间距 ≤ 25 000（CJJ 122-2017 第 12.3.1 条）
- **M-5.4** 池岸冲洗水量 1.5 L/(m²·次)，每次冲洗 ≥ 30 min，每天 ≥ 2 次（CJJ 122-2017 第 12.3.2 条）
- **M-5.5** 池岸排水坡度 ≥ 0.5%，并设独立排水沟（CJJ 122-2017 第 13.2.1-3 条）

**F — Forbidden（禁）**
- **F-5.1** 浸脚消毒池有效液深 < 150，或余氯不在 5~10 mg/L 范围
- **F-5.2** 池岸排水坡度 < 0.5%，或池岸冲洗水排入泳池循环系统

## 6 消防给排水

**M — Mandatory（应）**
- **M-6.1** 室内消火栓间距 ≤ 30 000（2 股水柱）／≤ 50 000（1 股水柱）（GB 50974-2014 第 7.4.10 条）
- **M-6.2** 栓口动压：高层或净空 > 8 m 的场所 ≥ 0.35 MPa 且充实水柱 13 m；其他场所 ≥ 0.25 MPa 且充实水柱 10 m；> 0.70 MPa 时应减压（GB 50974-2014 第 7.4.12 条）
- **M-6.3** 市政消火栓平时压力 ≥ 0.14 MPa、出水流量 ≥ 15 L/s、供水压力 ≥ 0.10 MPa（GB 55036-2022 第 3.0.3 条）
- **M-6.4** 消防水泵停泵应由人工控制，不应自动停泵（GB 55036-2022 第 3.0.11 条）
- **M-6.5** 每个灭火器配置计算单元内灭火器 ≥ 2 具，且最不利点位于 1 具灭火器的保护范围内（GB 55036-2022 第 10.0.2、10.0.3-2 条）

**F — Forbidden（禁）**
- **F-6.1** 消防水泵自动停泵
- **F-6.2** 灭火器配置计算单元内仅设 1 具灭火器
