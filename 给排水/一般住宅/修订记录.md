# 一般住宅给排水布置规则 修订记录

配套文件：《一般住宅给排水布置规则.md》（条文）、《一般住宅给排水布置规则-条文说明.md》（条文说明）。

| 版本 | 变更 |
|---|---|
| 2026-11-26 | 首次成文。依据 GB 55020-2021《建筑给水排水与节水通用规范》、GB 50015-2019《建筑给水排水设计标准》、GB 55038-2025《住宅项目规范》、GB 55031-2022、GB 55036-2022、GB 55037-2022、GB 50974-2014、GB 50140-2005、GB 50014-2021、GB 50336-2018、GB 50400-2016、GB 50736-2012、GB 50028-2006（2020 年版）、CJJ 12-2013、GB/T 11977-2008 建立条文与条文说明，编号体系 `M/R/F-章.条`，共 10 章。 |
| 2026-11-26 | 适用范围界定为**成套住宅**（最高入户层 ≤ 27 层、建筑高度 ≤ 100000）；别墅、老年照料设施、宿舍、旅馆式公寓、办公与商业建筑、住宅与商业合建体不适用本文件。 |
| 2026-11-26 | 强制性来源统一到全文强标：厨卫排水立管分设、排水管道不得穿越卧室、污废水不得排入雨水系统、水封 ≥ 50、套内用水点压力 ≥ 0.10、管道井每层封堵、卫生间位置限制、排水噪声 ≤ 33 dB(A) 等一律引 GB 55038-2025；GB 50096-2011 仅引未被废止的非强条。 |
| 2026-11-26 | 更正初稿两处面积数值：厨房使用面积 ≥ **3.5m²**（非 5.0m²）、卫生间三件套集中配置使用面积 ≥ **2.5m²**（非 5.0m²），依据 GB 55038-2025 第 4.1.4、4.1.6 条。 |
| 2026-11-26 | 更正灭火器依据：设计规范为 **GB 50140-2005** 第 6.1.3 条，GB 50444-2008 为验收与检查规范；并按 GB 55037-2022 第 8.1.1 条注明住宅套内可不配置灭火器。 |
| 2026-11-26 | 更正排水横管坡度数据：删除初稿误用的塑料管坡度，改为 GB 50015-2019 表 4.5.5（铸铁通用坡度/最小坡度）与表 4.5.6（塑料按外径通用坡度/最小坡度），并注明节水型大便器横支管按通用坡度确定。 |
| 2026-11-26 | 消防给水条目改按 GB 55037-2022 第 8 章标注条件：室内消火栓（> 21000）、自动灭火系统与火灾自动报警（> 100000）、水泵接合器（6 层及以上且设消火栓）、消防水池（GB 55036-2022 3.0.8-1）；新增室外消火栓流量 15 L/s、市政消火栓供水指标、栓口动压 0.35、消防水泵备用泵例外（< 54000 住宅）。 |
| 2026-11-26 | 补入 GB 55038-2025 第 7.2.6、7.2.7 条（暗卫生间机械通风、厨房排油烟道与防倒灌）、第 7.2.8 条（空调冷凝水专用立管不得倒坡）、第 4.2.13 条（太阳能热水与建筑一体化）、GB 55031-2022 第 6.7.1、6.7.2 条（管道井管线分设、井道独立）。 |
| 2026-11-26 | 补入 GB 50015-2019 表 4.4.11（最低横支管距立管管底）、第 4.6.2~4.6.5 条及表 4.6.3-1、4.6.3-2（检查口与清扫口）、表 4.5.1（器具排水流量与管径）、表 4.7.13（通气管最小管径）、第 4.5.2 条（排水秒流量 α = 1.5）、附录 E（管线净距）、第 4.5.4 条（排水秒流量公式）。 |
| 2026-11-26 | 补入燃气与器具安装类条目：GB 50028-2006（2020 年版）表 6.9.3（燃气表与燃具、电气设施净距）、CJJ 12-2013 第 4.3.1、4.3.2 条与表 4.8.1（热水器与灶具净距、房间净高、可燃材料间隔）、GB/T 11977-2008 第 5.6 条（洁具距墙尺寸）、GB 50096-2011 第 6.8 条（共用排气道接口直径与出口高度）。 |
| 2026-11-26 | 补入中水与雨水回用条目：GB 50336-2018 第 3.1.4、3.1.5、7.1.3、7.2.8、7.2.16 条，GB 50400-2016 第 4.1.3、4.3.2、5.1.8 条及回用雨水水质限值。 |
| 2026-11-26 | 版本状态说明更正：**GB 55020-2021 与 GB 50015-2019 均无 2024 年局部修订**（网传对照表实为 GB 50426-2016 的征求意见稿）；GB 50015-2019 的 29 条强条自 2022-04-01 起废止，强制性由 GB 55020-2021 承接；GB 50096-2011 全部强条自 2025-05-01 起废止、非强条仍现行；GB 50015-2003 整本废止，其"排水管道允许负荷当量总数"表不再引用。 |
| 2026-11-26 | 标准号勘误入册：二次供水工程技术规程为 CJJ 140-2010（GB/T 22244-2008 实为《保健食品中前叶青素的测定》）；卫生器具安装验收为 GB 50242-2002（CJJ/T 135 实为《透水水泥混凝土路面技术规程》）；GB 50974-2014 第 3.1.2 条无住宅内容；二次供水卫生规范按 GB 17051-2025（2026-06-01 实施）。 |
| 2026-11-26 | 新增附录 A《常用控制值速查》，统一列示压力、流速、坡度、充满度、管径、防水高度、面积、噪声、水温、消防流量与覆土净距等常用限值及其出处。 |
